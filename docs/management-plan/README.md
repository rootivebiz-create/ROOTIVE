# ROOTIVE GROUP 5カ年経営計画（2026–2031）

第一期中期経営計画の資料です。24 ページあり、ROOTIVE GROUP の「経営の憲法」として作りました。

| ファイル | 中身 |
|---|---|
| `ROOTIVE_GROUP_5year_plan_2026-2031.pptx` | 本体。PowerPoint（Windows / Mac）で開く |
| `ROOTIVE_GROUP_5year_plan_2026-2031.pdf` | 確認用の PDF（下の注意を参照） |
| `build.mjs` | 生成スクリプト。文言・数値・レイアウトはすべてここにある |
| `package.json` / `package-lock.json` | 生成に使うライブラリ（pptxgenjs・jszip） |

## 作り直し方

```bash
cd docs/management-plan
npm install
node build.mjs      # → ROOTIVE_GROUP_5year_plan_2026-2031.pptx
```

`node build.mjs` を実行すると、次の点検結果が一緒に表示されます。

- 文字がボックスからはみ出しそうなところ
- スライドの端に寄りすぎているところ
- 英字フォントに日本語が入っているところ
- 必須の図が抜けているところ

「点検：問題なし」と出れば、見た目の点検は通っています。

文言や数値を直すときは `build.mjs` を編集して作り直してください。PowerPoint で直接編集するとスクリプトと内容がずれるので、直接編集した場合はそちらを正としてください。

## 数値の扱い

- 確定しているのは、グループ連結売上高の**暫定経営目標**だけです。
  - FY2027 2億円
  - FY2028 5億円
  - FY2029 10億円
  - FY2030 18億円
  - FY2031 30億円
- 年度（FY）は 10 月から翌年 9 月までの 12 か月です（FY2027 は 2026 年 10 月〜2027 年 9 月）。
- ×15 と前年比は、上の暫定目標から計算した値です。
- 次のような数値は置いていません。財務モデルを作ってから確定し、資料には「財務モデル策定後に確定」と書いています。
  - 営業利益・EBITDA
  - M&A の件数・会社数・社員数
  - 借入額・現預金
  - KPI の目標値（連結売上を除く）
- 50億・100億・上場は長期の通過点です。時期は固定していません。
- p15 の A〜D 社は、構造を示すための例示です。

## フォント

| 使いどころ | フォント |
|---|---|
| 日本語の見出し | 游ゴシック（太字） |
| 日本語の本文 | 游ゴシック Medium |
| キーメッセージ | 游明朝 |
| 英字のラベル | Arial |
| 大きな英字・数字 | Cambria |

どれも Windows と Mac の PowerPoint に入っているフォントです。

同梱の PDF は、このリポジトリの環境（LibreOffice）で書き出したものです。そのため、游ゴシック・游明朝の代わりに見た目の近い Noto Sans JP・Noto Serif JP が使われています。また、和文と英数字の間に細い空白が入ります。PowerPoint と同じ見た目の PDF が必要なときは、PowerPoint で開いて「ファイル → エクスポート → PDF」で書き出してください。
