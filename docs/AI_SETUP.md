# AI 機能の準備（Anthropic API キーの取り方）

このアプリの AI 機能（月次の分析と改善策・AI チャット・文章の下書き）は、Anthropic の API キーを登録すると使えるようになります。
キーが未登録のあいだは、AI の画面は「準備ができていません」と表示されるだけで、他の機能には一切影響しません。

---

## 1. API キーを取る（10 分ほど）

### 手順
1. **アカウントを作る**
   <https://console.anthropic.com> を開き、「Sign up」からアカウントを作ります。
   ログインは Google アカウントでもできます（`rootive.biz@gmail.com` でかまいません）。
   ※ これは ChatGPT や Claude の月額プラン（Claude Pro など）とは**別の契約**です。Claude Pro に入っていても API は使えません。

2. **組織の名前を入れる**
   最初に組織名を聞かれるので「株式会社ROOTIVE」などと入れます。あとから変えられます。

3. **クレジットを買う（前払い）**
   左メニューの **Billing（お支払い）** → 「Add credits」または「Buy credits」。
   クレジットカードを登録して、まずは **$5（約 800 円）** だけ入れれば十分です。
   使った分だけ減っていく前払い方式で、自動で引き落とされ続けることはありません。

4. **API キーを発行する**
   左メニューの **API keys** → 「Create Key」。
   - Name：`rootive-profit`（分かりやすい名前なら何でも）
   - Workspace：`Default`
   発行されたキー（`sk-ant-api03-…` で始まる長い文字列）が**その場で 1 回だけ**表示されます。
   **必ずコピーしてメモ帳などに控えてください。**閉じると二度と見られません（見失ったら作り直せます）。

5. **使いすぎ防止の上限を入れる（おすすめ）**
   **Billing → Usage limits** で、月あたりの上限（例：$20）と、8 割に達したときのメール通知を設定しておくと安心です。

## 2. アプリに登録する

このアプリは GitHub Actions から本番へ反映しているので、キーは **GitHub の Secrets** に入れます。

1. <https://github.com/rootivebiz-create/ROOTIVE> を開く
2. **Settings** → 左メニュー **Secrets and variables** → **Actions**
3. **New repository secret**
   - Name: `ANTHROPIC_API_KEY`
   - Secret: さきほどコピーしたキー（`sk-ant-api03-…`）
4. **Add secret** で保存

保存したら、**Actions → Deploy → Run workflow** をもう一度実行してください。
デプロイのときに Vercel の環境変数へ自動で入り、AI 機能が使えるようになります。

> モデルを変えたいときは、同じ手順で `ANTHROPIC_MODEL` という Secret を足します（未設定なら `claude-sonnet-5` を使います）。

### 登録できているかの確認
- アプリの **設定 → 外部連携** に「AI：利用できます」と出ていれば OK です。
- **AI** の画面で「今月の分析を作る」を押して、所見と改善策が出れば完了です。

## 3. 料金の目安

使った分だけの従量課金です。1 回あたりの目安は次のくらいです（Sonnet クラス・2026 年 9 月時点の単価での概算）。

| 使い方 | 1 回あたりの目安 |
| --- | --- |
| 月次の分析と改善策 | 8〜15 円 |
| AI チャットの 1 往復 | 5〜12 円 |
| 文章の下書き | 3〜8 円 |

現実的な使い方での月額の目安：

| 使い方の例 | 月額の目安 |
| --- | --- |
| 月次の分析だけ（月 5 回） | 50〜100 円 |
| ふつうに使う（分析 10 回＋チャット 100 往復＋文章 20 回） | 700〜1,500 円 |
| かなり使う（チャット 500 往復） | 3,000〜6,000 円 |

最初に入れた $5（約 800 円）でも、月次の分析なら半年以上もちます。
実際の残高と使用量は **console.anthropic.com → Usage** でいつでも見られます。単価は変わることがあるので、正確な金額は
<https://www.anthropic.com/pricing> を確認してください。

## 4. 安全のために

- API キーは**パスワードと同じ**です。LINE やメールで送らないでください。
- 万一もれたら、console の **API keys** で該当のキーを削除（Revoke）して作り直し、GitHub Secrets を入れ替えて再デプロイすれば元に戻ります。
- キーはブラウザ（お客さまの画面）には一切渡っていません。サーバー側だけで使っています。
- AI に渡しているのは**この会社の集計された数字**（売上・利益・経費・案件・ドライバー名など）です。
  個人情報（口座番号・住所・電話番号）は渡していません。
- Anthropic は API 経由で受け取ったデータを既定でモデルの学習には使いません。

---

## 5. うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| 「ANTHROPIC_API_KEY が設定されていません」 | Secrets に入れたあと、デプロイをやり直していない |
| 「ANTHROPIC_API_KEY が無効です」 | キーの貼り付け間違い（前後の空白・改行）。作り直して入れ直す |
| 「AI の利用制限に達しました」 | 短時間に呼びすぎ。少し待つ |
| 「credit balance is too low」系のエラー | クレジット残高切れ。Billing でチャージする |
| 「モデルが見つかりません」 | `ANTHROPIC_MODEL` の指定が誤り。この Secret を消せば既定に戻る |
