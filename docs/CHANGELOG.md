# 変更履歴

## 2026-09-16 ドライバー別単価と便利機能

オーナー要望「ドライバーごとに単価設定できるようにしてほしい」への対応と、あわせて追加した機能。

### ドライバー別単価（主機能）

- **受注単価もドライバーごとに設定できるようになりました。** これまでは支払単価だけでした（`driver_pay_overrides.bill_rate` を追加。受注・支払のどちらか一方だけの上書きも可）。
- **設定 → ドライバー別単価** 画面を新設。「ドライバーごと」（ドライバーを選んで案件内容ごとに入力）と「案件ごと」（案件内容を選んでドライバーごとに入力）の 2 つの見方。個別値には「個別」バッジ、支払 > 受注 は「赤字」。
- ドライバー編集画面の「ドライバー別単価」カードにも受注単価欄を追加。案件編集画面から「ドライバー別単価」へ移動できます。
- 稼働の自動入力（§2.5）は受注・支払ともドライバー別単価を優先します。稼働追加ダイアログには「ドライバー別」の表示。
- 単価表 CSV（全員 × 全案件内容の実効単価）。

### 単価変更を稼働に反映

- 単価・率・端数処理を変えた後、入力済みの稼働行は入力時点の値のまま（仕様）。**稼働入力**に「単価・率が現在の設定と異なる稼働行が ○ 件あります」の案内と **「マスタの値に更新」**（行ごとにチェックして一括更新）、行には「単価変更あり」バッジ。
- **設定 → ドライバー別単価** の保存後に「○年○月 の稼働に反映」。
- **ダッシュボード**の警告に「単価・率が現在の設定と異なる稼働行」を追加（締め済み月には出ません）。
- DB：`rate_diffs(month)`、`apply_master_rates(month, driver_id?, project_item_id?, entry_ids?)`（admin 以上・未締め月のみ・監査ログに記録）。

### 全員分の明細 PDF を一括ダウンロード

- **支払** 一覧の **「全員分の PDF（ZIP）」** で、その月の全ドライバーの PDF 明細を 1 つの ZIP に。
