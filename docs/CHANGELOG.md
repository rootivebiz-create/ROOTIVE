# 変更履歴

## 2026-09-18 経費と営業利益・取引先と請求書・年次レポート・月次目標・ポータルの速報

オーナー要望「もっと進化させてほしい。便利な機能をどんどん追加してほしい」への大型アップデート。会社の**本当の利益（営業利益）**、**売上側の請求書**、**年次レポート**、**目標管理**、**ドライバーへの速報**を追加しました。

### 経費と営業利益（新規）

- **経費**（下タブ「メニュー」→ 経費／PC は左メニューの「経費」）を追加。カテゴリ別の小計と月合計（固定費／変動費）を表示し、1 件ずつ登録・編集・削除できます。金額はすべて**税抜**。返金はマイナスで入力します。
- **設定 → 経費カテゴリ**：カテゴリ（固定費／変動費）の追加・並び替え・停止と、**毎月かかる経費**（車両リース・保険料など）の登録。会社を作った時点で 12 個の既定カテゴリが入っています。
- 経費の画面の **「毎月かかる経費をこの月に計上」** で、その月の経費としてまとめて計上できます（何度押しても二重計上しません）。
- **営業利益 ＝ 会社利益 − 経費**。ダッシュボードの KPI に「経費」「営業利益」を追加し、経費のカテゴリ別内訳カードと「この月の経費が 1 件も登録されていません」の警告も出るようにしました。
- 経費 CSV（その月／全月）を追加。締め済み月の経費は変更できません（稼働と同じ扱い）。

### 取引先と請求書（新規）

- **設定 → 取引先**：取引先（元請・荷主）のマスタ。名称・敬称・住所・電話・適格請求書登録番号・**入金予定日**（当月〜3 か月後 × 末日／1〜31 日）を登録します。
- **設定 → 案件・単価**の案件フォームで取引先を選べるようになりました（これまでの「荷主・元請」の手入力を置き換え）。
- **請求書**（下タブ「請求」）：その月の取引先ごとの売上（税抜）と請求書の状態を一覧で確認し、**「請求書を作成」** でその月の稼働から請求明細（案件内容 × 受注単価ごとに 1 行）を自動で作ります。請求書番号は `YYYYMM-01` から自動採番。
- 請求書の詳細では、明細の手直し（追加・編集・削除）、請求書番号・発行日・入金予定日・備考の編集、**下書き → 発行済み → 入金済み**の状態管理（入金日つき）ができます。発行済みの請求書は明細を変更できません（下書きに戻せば可）。
- **請求書 PDF**（A4・会社のロゴと認印つき）と**印刷用ページ**、**請求書一覧 CSV**。合計・消費税はデータベース側で自動計算します。

### 年次レポート（新規）

- **レポート**（PC は左メニュー、スマホは「メニュー」）に年次レポートを追加。年を選ぶと、年間サマリー（売上・会社利益・経費・営業利益・営業利益率・支払・消費税）、**月次の推移グラフ**、月次の表（12 か月＋合計）、**前年比**、**ドライバー別ランキング**、**案件別ランキング**、**経費のカテゴリ別内訳**が出ます。
- 年次レポート CSV（月次推移＋合計行）。

### 月次目標（新規）

- ダッシュボードに **月次目標** カード。売上目標・営業利益目標を設定すると、達成率と残り金額が進捗バーで出ます（管理者以上が設定）。

### ドライバーポータルの強化

- **当月の速報**：締める前の月でも、税込のお支払予定額・内訳・振込予定日を「集計中」として表示します（「締め前のため変わることがあります」の注意書きつき）。**設定 → 会社設定**のスイッチで表示を止められます。
- **年間サマリー**：年ごとのお支払額の合計と締め済み月数、月別の内訳。

## 2026-09-16 税込の支払明細・消費税設定・ロゴと認印・ドライバーごとの支払日

オーナー要望「支払明細が税込になっていない（単価は全部税別で入力する）」「認印とロゴを明細に」「ドライバーによって支払日が違う」「税設定」への対応。

### 税込の支払明細

- **単価・管理費・ロイヤリティはすべて税抜で入力**し、支払明細で消費税を計算して **税込のお支払額** を出します。
  - 税抜小計 ＝ 稼働小計 − ロイヤリティ − 管理費
  - 消費税 ＝ 税抜小計 × 税率（端数処理は会社設定。既定は切り捨て）
  - お支払額（税込）＝ 税抜小計 ＋ 消費税 ＋ 調整
  - **調整（固定控除・立替など）は税込の金額として扱い、消費税を計算しません。**
- PDF・印刷用ページ・スタッフ画面・ドライバーポータル・LINE 用テキスト・個人明細 CSV のすべてで「小計（税抜）」「消費税（10%）」「お支払額（税込）」の順に表示します。
- 支払一覧と支払一覧 CSV に「消費税」「税込支払額」を追加。ダッシュボードの「ドライバー支払合計」と会社利益は従来どおり税抜です。
- 締めた月は、締めた時点の税率・端数処理・課税区分で固定されます（`driver_months.tax_*`）。締めを解除すると現在の設定に従います。

### 税設定

- **設定 → 会社設定 → 「消費税」**：消費税率（既定 10%）と消費税額の端数処理（切り捨て／四捨五入／切り上げ）。
- **設定 → ドライバー → 「消費税・支払日」**：課税区分（課税＝消費税を上乗せ／非課税・免税＝上乗せしない）と適格請求書登録番号（任意。明細に印字）。

### ロゴ・認印

- **設定 → 会社設定 → 「ロゴ・認印」** で PNG／JPEG（2MB まで）をアップロードすると、PDF と印刷用ページに印字されます（ロゴは会社名の上、認印は会社情報の横）。画像は非公開の Storage（`company-assets`）に保存し、ログイン中の自社ユーザーだけが `/api/company-asset/logo|seal` で参照できます。

### ドライバーごとの支払日

- **設定 → ドライバー → 「消費税・支払日」** で「振込予定日は会社設定に従う」を外すと、支払月（当月〜3 か月後）と支払日（末日／1〜31 日）をそのドライバーだけ変えられます。明細・ポータル・テキスト・CSV の振込予定日に反映します。

### その他

- マイグレーション `0008_tax_assets_payout.sql`。既存の本番環境は GitHub Actions の「本番公開」で自動適用されます。
- バックアップ JSON に税率・端数処理・課税区分・登録番号・支払日を含め、復元でも戻ります（ロゴ・認印の画像はバックアップに含まれないため、復元後に再アップロードしてください）。

## 2026-09-16 ドライバー別単価と便利機能

オーナー要望「ドライバーごとに単価設定できるようにしてほしい」への対応と、あわせて追加した機能。

### ドライバー別単価（主機能）

- **受注単価もドライバーごとに設定できるようになりました。** これまでは支払単価だけでした（`driver_pay_overrides.bill_rate` を追加。受注・支払のどちらか一方だけの上書きも可）。
- **設定 → ドライバー別単価** 画面を新設。「ドライバーごと」（ドライバーを選んで案件内容ごとに入力）と「案件ごと」（案件内容を選んでドライバーごとに入力）の 2 つの見方。個別値には「個別」バッジ、支払 > 受注 は「赤字」。
- ドライバー編集画面の「ドライバー別単価」カードにも受注単価欄を追加。案件編集画面から「ドライバー別単価」へ移動できます。
- 稼働の自動入力（§2.5）は受注・支払ともドライバー別単価を優先します。稼働追加ダイアログには「ドライバー別」の表示。
- 単価表 CSV（全員 × 全案件内容の実効単価）。

### 単価変更を稼働に反映

- 単価・率・端数処理を変えた後、入力済みの稼働行は入力時点の値のまま（仕様）。**稼働入力**に「単価・率が現在の設定と異なる稼働行が ○ 件あります」の案内と **「マスタの値に更新」**（行ごとにチェックして一括更新）、行には「単価変更あり」バッジ。
- **設定 → ドライバー別単価** の保存後に「○年○月 の稼働に反映」。
- **ダッシュボード**の警告に「単価・率が現在の設定と異なる稼働行」を追加（締め済み月には出ません）。
- DB：`rate_diffs(month)`、`apply_master_rates(month, driver_id?, project_item_id?, entry_ids?)`（admin 以上・未締め月のみ・監査ログに記録）。

### 全員分の明細 PDF を一括ダウンロード

- **支払** 一覧の **「全員分の PDF（ZIP）」** で、その月の全ドライバーの PDF 明細を 1 つの ZIP に。
