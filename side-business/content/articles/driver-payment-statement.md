> **この記事のまとめ**
>
> - ドライバーが納得する明細は、「何を・いくつ・いくらで」の内訳と、差し引いたものの根拠が1枚で分かる明細です。
> - 管理費・ロイヤリティ・リース代は、取引条件で示した名前と金額（割合）のとおりに書き、消費税も分けて書きます。振込手数料は差し引きません。
> - Excelで作るなら、単価表と端数の決まりを1か所にまとめ、誰が締めても同じ数字になる形にしておきましょう。

この記事は、2026年9月時点の国税庁・公正取引委員会の資料にもとづいています。金額と明細は、すべて書き方の例です。税金と法律の最終的な判断は、税理士・弁護士・社労士に確かめてください。

## 支払明細が大事な理由

ドライバーにとって、支払明細は1か月の仕事の答え合わせです。合計の金額だけが書いてあると、「個数が合っているか」「何を引かれたのか」が分かりません。問い合わせが増え、会社への信頼も下がります。

会社にとっても、明細は大事な記録です。

- **フリーランス法**：従業員を使わずに1人で走るドライバーに仕事を頼んだら、単価や支払期日などの取引条件を、すぐに書面かメール・LINEなどで示す必要があります。明細は「示した条件のとおりに計算して払った」ことの記録になります。
- **消費税**：インボイス登録しているドライバーなら、会社が作ってドライバーに確認してもらう明細は、決められた事項を書けば「仕入明細書」として、仕入税額控除に使えます。
- **あとからの説明**：単価や差し引くものを変えたとき、いつから何が変わったかを明細で説明できます。

2026年9月2日には、公正取引委員会が日本郵便に、フリーランス法にもとづく勧告をしました。取引条件をすぐに示していなかったことや、支払期日を決めず期日までに払っていなかったことが理由です。条件と明細と振込の記録は、ドライバーごとにそろえて残しておきましょう。

## 明細に書く項目

| 項目 | 書くこと |
| --- | --- |
| 宛名と作成者 | ドライバーの名前、会社名。インボイス登録している方は双方の登録番号 |
| 対象期間 | 締めの期間（例：10月1日〜10月31日） |
| 稼働の内訳 | 仕事の内容・数量・単価・金額 |
| 委託料と消費税 | 税抜の合計と、10%の消費税 |
| 差し引くもの | 管理費・ロイヤリティ・リース代と、その根拠 |
| 調整 | 立替金の精算など、その月だけの足し引き |
| 振込額・振込日 | 最後に振り込む額と、その日付 |

### 記入例（インボイス登録済みのドライバー・10月分）

- 作成者：〇〇運送株式会社（登録番号 T＋13桁）
- 宛名：〇〇 〇〇 様（登録番号 T＋13桁）
- 対象期間：2026年10月1日〜10月31日（月末締め）
- 振込日：2026年11月25日（水）

**① 委託料**

| 仕事の内容 | 数量 × 単価 | 金額 |
| --- | --- | --- |
| 宅配（個建て） | 1,840個 × 150円 | 276,000円 |
| スポット便 | 4件 × 7,000円 | 28,000円 |
| 小計（10%対象） | | 304,000円 |
| 消費税 | 304,000円 × 10% | 30,400円 |
| 委託料（税込） | | 334,400円 |

**② 差し引くもの**

| 名前 | 根拠 | 金額 |
| --- | --- | --- |
| ロイヤリティ | 委託料（税抜）× 5% | 15,200円 |
| 管理費 | 月額（稼働がある月） | 10,000円 |
| 車両リース代 | 稼働22日 × 1,500円 | 33,000円 |
| 小計（10%対象） | | 58,200円 |
| 消費税 | 58,200円 × 10% | 5,820円 |
| 差し引く合計（税込） | | 64,020円 |

**③ 調整（消費税の対象外）**

| 内容 | 金額 |
| --- | --- |
| 駐車場代の立替（10月14日・領収書あり） | ＋3,300円 |

**振込額 ＝ 334,400円 − 64,020円 ＋ 3,300円 ＝ 273,680円**

委託料と差し引くものを分け、それぞれに消費税を出しているのがポイントです。振込額だけを書くより、ドライバーも税理士も確かめやすくなります。

## 差し引くもの（管理費・ロイヤリティ・リース）の書き方

差し引くものは、取引条件で示した名前と金額（割合）のとおりに書きます。明細だけに出てくる名前や、条件と違う金額は書かないようにしましょう。

### 管理費

月額なら「月額」、稼働がない月は引かないなら「稼働がある月」と、条件どおりに書きます。月の途中から始めた人を日割りにするなら、日数も書きます。

### ロイヤリティ

**何に対する割合か**を書きます。税抜の委託料か、税込か。どの案件の分か。割合をかけたあとの1円未満の扱い（切り捨て・四捨五入）も、毎月同じにします。

### リース代

月額か、稼働1日あたりかを書きます。日数で計算するなら、その月の稼働日数を明細に書きます。リースを使うかどうかは、本人が選べるようにしておきましょう。従業員を使っている会社などが1か月以上続く仕事を頼む場合、正当な理由なく会社が指定するリースを使わせると、フリーランス法で禁止されている行為にあたるおそれがあります。

### 振込手数料は差し引かない

公正取引委員会は、フリーランス法について「これまでは、合意していれば振込手数料を報酬から差し引いて払っても問題なかったが、2026年1月1日以降に発注する取引からこの考え方が変わる」と案内しています。会社の資本金や従業員数によって対象になる取適法（旧下請法）では、2026年1月1日から、合意の有無にかかわらず、振込手数料を代金から差し引くと「減額」として違反になると示されています。振込手数料は差し引かず、会社で負担するのが安全です。

### 決めていないものは引かない

従業員を使っている会社などが1か月以上続く仕事を頼む場合、ドライバーに責任がないのに、決めた報酬を後から減らすことは禁止されています。名目にかかわらず、決めた金額から差し引くと「減額」にあたるおそれがあります。誤配の罰金や事故の弁償などを差し引く取り決めは判断が難しいので、弁護士に確かめてください。

## 消費税の書き方

### インボイス登録済みのドライバー

会社が作る明細を仕入明細書として使うには、国税庁の案内では次の事項が必要です。

- 明細を作った会社の名前
- ドライバーの名前と登録番号
- 仕事をしてもらった日（まとめるなら期間）
- 仕事の内容
- 税率ごとに合計した金額と税率
- 税率ごとの消費税額

また、ドライバーの確認を受けたものであることが必要です。たとえば「送ってから一定の期間に誤りの連絡がなければ、確認したものとする」と前もって取り決めておく方法が、国税庁のQ&Aで示されています。

管理費やリース代が、会社がドライバーに提供するサービスや車の貸し出しの代金なら、会社の売上として消費税がかかります。国税庁のQ&Aには、仕入明細書と、会社が出す適格請求書を1枚の書類にまとめる場合の説明もあり、その場合は両方の記載事項が必要です。どう扱うかは契約の中身で変わるので、税理士と決めてください。

登録番号は、国税庁の公表サイトで確かめられます。登録をやめた方がいないか、ときどき見直しましょう。

### 免税のドライバー

登録番号がないので、仕入明細書の要件は満たしません。ただ、原則課税の会社なら、経過措置により、支払にふくまれる消費税の一部を控除できます。控除できる割合は、2026年10月1日以降の仕事の分から80%が70%に下がります。帳簿に経過措置の対象であることを書き、区分記載請求書と同じ事項を書いた明細などの書類を保存しておきます。

会社の負担がいくら増えるかは[控除70%の計算例の記事](/articles/invoice-70-percent-driver)で、20日締めなど月の途中で締める場合は[締め日と80%・70%の記事](/articles/shimebi-80-70)で確かめられます。免税だからといって、決めた報酬から消費税分を話し合いなしに差し引くと、減額にあたるおそれがあります。

## 調整の書き方

立替金の精算（会社の代わりにドライバーが払った費用を返すもの）など、その月だけの足し引きは「調整」として、委託料とは分けて書きます。1行ずつ、内容・日付・根拠（領収書など）を書きます。

前の月の数量の数え間違いを直すときは、調整にまとめず、「9月分の修正 3個 × 150円」のように数量と単価で書きます。委託料の直しなので、消費税もかかるからです。書き方は税理士と決めておきましょう。

## 振込額と振込日

振込額は「委託料（税込）− 差し引くもの（税込）± 調整」です。式を明細の下に書いておくと、ドライバーが自分で確かめられます。

振込日は、取引条件で決めた支払期日を書きます。従業員を使っている会社などは、支払期日を仕事をしてもらった日から60日以内の、できるだけ短い期間で決める必要があります。締め日と支払日の組み合わせは、[60日の数え方の記事](/articles/payment-60-days)で確かめられます。振込先は、銀行・支店と口座番号の下4桁くらいにしておくと、明細を人に見られても安心です。

## よくある間違い

| 間違い | 防ぎ方 |
| --- | --- |
| 合計の金額だけで、数量と単価がない | 案件ごとに数量 × 単価の行を出す |
| 差し引くものの名前や額が、条件と違う | 条件書と同じ言葉・同じ計算で書く |
| ロイヤリティを税抜にかける月と税込にかける月がある | かける元を明細に書き、式を1つにする |
| 稼働がない月にも管理費を引いている | 条件どおりに「稼働がある月だけ」などを式にする |
| 振込手数料を差し引いている | 会社負担にする |
| 前の月の直しを調整にまとめ、消費税がずれる | 数量 × 単価の行で直す |
| LINEやメールで送ったPDFを残していない | 送ったデータも決まった場所に保存する |

LINEやメールで明細のPDFを送った場合、送った側にもデータの保存が求められます（電子取引データの保存）。また、仕入税額控除のための請求書等（仕入明細書をふくむ）は、原則7年間の保存が必要です。詳しい保存の方法は税理士に確かめてください。

## Excelで作るときの式のコツ

シートを3つに分けると、式がシンプルになります。

- 単価表：A列に案件、B列に支払単価
- 稼働（1か月分）：A列 ドライバー、B列 日付、C列 案件、D列 数量、E列 単価、F列 金額
- 明細：A列 ドライバー、B列 委託料、C列 管理費の月額、D列 ロイヤリティの割合

| したいこと | 式の例 |
| --- | --- |
| 稼働：単価を単価表から引く | `=XLOOKUP(C2,単価表!A:A,単価表!B:B)`（古いExcelならVLOOKUP） |
| 稼働：行の金額（1円未満を四捨五入） | `=ROUND(D2*E2,0)` |
| 明細：ドライバーごとの委託料 | `=SUMIFS(稼働!F:F,稼働!A:A,A2)` |
| 明細：稼働がある月だけ管理費 | `=IF(B2>0,C2,0)` |
| 明細：ロイヤリティ（切り捨て） | `=ROUNDDOWN(B2*D2,0)` |
| 明細：消費税（切り捨て） | `=ROUNDDOWN(B2*10%,0)` |

- 単価を式の中に直接書かず、単価表を見るようにします。単価を変えるときは上書きせず、「いつから」の列を足すと、過去の明細を作り直せます。
- 端数の扱いは条件に合わせて1つに決め、全部の式で同じにします。
- 手で入れるセルと式のセルの色を分け、式のセルはシートの保護で守ります。
- 最後に、明細の振込額の合計、振込データの合計、口座から出ていく額（会社が負担する振込手数料を除く）の3つが同じか確かめます。

## 担当者しか分からない、をなくすには

Excelそのものが悪いわけではありません。困るのは、式を作った人しか直せない、行を足すと集計の範囲がずれる、担当者が休むと締まらない、という状態です。

まず、単価・差し引くもの・端数の扱い・締め日と振込日を、1つの台帳に書き出しましょう。これが決まっていれば、誰が締めても同じ数字になります。

そのうえで、仕組みにすれば、数量を入れると明細・振込データ・案件ごとの集計が同じ台帳から出るようにできます。人が見るのは、数量と調整のような例外に絞れます。切り替えるときは、最初の1か月は今のExcelと並べて締め、差がないことを確かめてからにすると安心です。

## しめ日ラボでできること

しめ日ラボでは、今の単価の決め方・差し引くもの・端数の扱いのまま、支払明細と銀行の振込データを同じ台帳から作る仕組みを、御社のアカウントに作ります。この記事の記入例のような明細ができるまでは、架空のデータで動く[デモ](/demo)でさわれます。取引条件の書面を見直すなら[取引条件明示書のツール](/tools/torihiki-joken)も使えます。ご相談は[お問い合わせ](/contact)からどうぞ。
