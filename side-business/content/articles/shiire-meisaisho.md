> **この記事のまとめ**
>
> - 会社が作ってドライバーに渡す支払明細は、決められた事項を書き、ドライバーの確認を受ければ「仕入明細書」になります（ドライバーがインボイスの登録をしている場合）。ドライバーから毎月インボイスをもらわなくても、消費税の控除の書類として使えます。
> - 書くことは6つです。作成者、ドライバーの名前と登録番号、年月日（期間）、仕事の内容、税率ごとの合計額と税率、税率ごとの消費税額です。
> - 確認は「一定期間内に誤りの連絡がなければ確認したものとする」という形でも取れます。登録番号は国税庁の公表サイトで確かめ、免税のドライバーの明細とは分けて作りましょう。

この記事は、2026年9月時点の国税庁の資料にもとづいています。明細の例や金額は、すべて説明のための例です。税金の最終的な判断は、顧問の税理士に確かめてください。

## 支払明細が「仕入明細書」になるとは

会社が消費税を計算するとき、ドライバーに払った委託料にふくまれる消費税を差し引けます。これを「仕入税額控除」といいます。差し引くには、帳簿と「請求書等」の保存が必要です。

この「請求書等」には、2つの形があります。

| | インボイス<br>（適格請求書） | 仕入明細書 |
| --- | --- | --- |
| 作る人 | ドライバー<br>（仕事を受けた側） | 会社<br>（仕事を頼んだ側） |
| 登録番号 | ドライバーの番号 | ドライバーの番号 |
| 相手の確認 | いらない | 必要 |

軽貨物の会社では、ドライバーが請求書を出すより、会社が支払明細を作って渡すことが多いと思います。その支払明細を仕入明細書の形にしておけば、ドライバーに毎月インボイスを出してもらわなくても済みます。

法律の言葉では「仕入明細書、仕入計算書その他これらに類する書類」です。名前が「支払明細書」や「支払通知書」でも、書く事項がそろっていればかまいません。ドライバーにも分かるよう「支払明細書（兼 仕入明細書）」と書いておくと親切です。

なお、仕入明細書として使えるのは、ドライバーがインボイスの登録をしている（適格請求書発行事業者である）場合です。登録していない免税のドライバーの明細は、あとの章で説明します。

## 書くことは6つ

国税庁の資料では、仕入明細書に次の事項を書くことになっています。

| 記載事項 | 支払明細での書き方（例） |
| --- | --- |
| ① 作成者の氏名または名称 | 会社名 |
| ② 相手方の氏名または名称と登録番号 | ドライバーの氏名（屋号）と、T＋13桁の番号 |
| ③ 課税仕入れを行った年月日 | 仕事をしてもらった日。月でまとめるなら対象期間 |
| ④ 資産または役務の内容 | 「軽貨物配送の業務委託（A便）」など |
| ⑤ 税率ごとに合計した支払対価の額と適用税率 | 「10%対象 363,000円（税込）」 |
| ⑥ 税率ごとに区分した消費税額等 | 「消費税額（10%） 33,000円」 |

⑤の「支払対価の額」は税込の金額です。国税庁のQ&Aでは、税抜の合計額と消費税額を税率ごとに分けて書く形でもよいとされています。下の明細の例は、税抜・消費税額・税込の3つをのせています。

### ③ 年月日は「期間」でもよい

毎日の仕事を月でまとめて明細を作るなら、日ごとに書かなくても、対象期間（例：2026年10月1日〜10月31日）でかまいません。ただし、まとめる期間は課税期間（会社の事業年度など）の範囲内で、とされています。20日締めなどで決算月をまたぐ会社は、書き方を税理士に確かめてください。

### ④ 内容は「何の仕事か」が分かるように

「委託料」だけより、「軽貨物配送の業務委託」と案件名を書くほうが分かりやすくなります。案件ごとに行を分けておくと、ドライバーも確かめやすくなります。配送の委託料は、ふつう10%の対象です。

### ⑥ 消費税の端数は、明細1枚につき税率ごとに1回

国税庁のQ&Aでは、インボイス（適格請求書）の消費税額の1円未満の端数は、1枚ごとに、税率ごとに1回だけ処理するとされています。行ごと（日ごと・案件ごと）に端数を切って足し合わせる方法は認められていません。切り捨て・切り上げ・四捨五入のどれにするかは、事業者が決めてかまいません。

仕入明細書も、同じく「1枚につき税率ごとに1回」で作っておくと安全です。いまの明細の計算のしかたでよいかは、税理士に確かめてください。

たとえば、3つの案件の委託料（税抜）が12,345円・23,456円・34,567円だったとします（切り捨ての例）。

| 計算のしかた | 消費税額 |
| --- | --- |
| 合計70,368円 × 10% ＝ 7,036.8円 → 1回で切り捨て | 7,036円 |
| 行ごとに切り捨てて足す（1,234円＋2,345円＋3,456円） | 7,035円（インボイスでは認められない方法） |

Excelで行ごとに消費税を出している会社は、1円ずれることがあります。合計から1回で出す形にしておきましょう。

| 項目 | 例 |
| --- | --- |

| 作成者 | 株式会社〇〇運送 |
| 宛先 | 〇〇 〇〇 様<br>登録番号 T＋13桁 |

| 消費税額（10%） | 33,000円 |

| 確認の文言 | 次の章の例文 |

## ドライバーの「確認」の取り方

仕入明細書は、書いた内容について相手（ドライバー）の確認を受けたものでなければなりません。国税庁の通達（消費税法基本通達11-6-6）では、確認の取り方の例として、次の3つが示されています。

1. 明細の内容を相手の画面に出し、確認の返事を受けてから出力する。
2. 明細のデータをメールなどで送り、相手から「確認しました」という連絡をもらう。
3. 明細（写し）やデータを渡し、「一定期間内に誤りの連絡がなければ、書いた内容のとおり確認があったものとする」と取り決めておき、その期間が過ぎる。

毎月、ドライバー全員から返事を集めるのは手間がかかります。3の形にしておくと、実務では回しやすくなります。

### 明細に書く文言（例）

国税庁のQ&Aでは、3の取り決めを契約で結ぶほか、その文言を明細そのものや、明細につける通知の文書に書いて送り、相手の了承を得る方法も示されています。例として「送付後一定期間内に誤りのある旨の連絡がない場合には記載内容のとおり確認があったものとします」という書き方が載っています。

支払明細に書くなら、たとえば次のような文言です。

> 記載内容に誤りがある場合は、受け取った日から7日以内にご連絡ください。期間内にご連絡がない場合は、記載内容のとおり確認いただいたものとします。

日数は、御社とドライバーで決めてください。はじめてこの形にするときは、ドライバーに一度説明して了承をもらい、その記録（メールやチャット）を残しておくと安心です。

### 業務委託契約書にも入れておく

新しく契約するドライバーには、業務委託契約書に同じ取り決めを入れておく方法もあります。条文の書き方は、弁護士や税理士に確かめてください。

### 誤りの連絡があったら

内容を直した明細を作り、あらためて確認を受けます。直した明細と前の明細は、両方残しておきましょう。直し方の細かい点は、税理士に確かめてください。

### 確認の期間と、支払期日は別の話

確認の期間を置いても、支払を遅らせてよいわけではありません。フリーランス法（2024年11月施行）では、従業員を雇っている会社が、従業員を使わない個人のドライバーに仕事を頼む場合、支払期日は仕事をしてもらった日から60日以内の、できるだけ短い期間で決める必要があります。報酬の額や支払期日などの取引条件は、支払明細とは別に、仕事を頼むときにすぐ書面かメールなどで示す必要もあります。詳しくは[取引条件明示書の書き方](/articles/torihiki-joken-template)と[支払期日の確かめ方](/articles/payment-60-days)をご覧ください。

## 登録番号の確かめ方と管理

仕入明細書に書く登録番号は、「T」と13桁の数字です。個人のドライバーの番号は、マイナンバーとは別の番号です。

番号は、国税庁の「適格請求書発行事業者公表サイト」で確かめられます。番号を入れると、名前や登録日が出ます。取消や失効があれば、その日も出ます。取引の日に登録があったかを確かめるときに使えます。

| いつ | すること |
| --- | --- |
| 契約するとき | 番号を聞き、公表サイトで名前と登録日を確かめる。台帳に記録する |
| 毎月の締めの前 | 登録の取消や失効がないか確かめる |
| 登録した・やめたと聞いたとき | 登録日や失効日を台帳に記録し、その日から明細の書き方を切り替える |

ドライバーが多い会社は、国税庁のWeb-API（利用には事前にアプリケーションIDの発行を受ける手続きが必要）や、公表サイトのダウンロードデータを使って、まとめて確かめる方法もあります。

月の途中で登録したドライバーは、登録日の前と後で扱いが変わります。登録日の前の分と後の分で明細の行を分けておくと、あとで確かめやすくなります。どう分けるかは税理士に確かめてください。

## 免税（未登録）のドライバーの明細

登録番号がないドライバーの支払明細は、インボイスの代わりとしての仕入明細書にはなりません。

ただ、経過措置で一定の割合は控除できます。この割合は、2026年10月1日から80%が70%に下がります（2028年9月30日まで。令和8年度税制改正）。経過措置を使うには、次の2つを保存する必要があります。

- 区分記載請求書等と同じ事項が書かれた請求書等
- 経過措置の対象であること（例：「70%控除対象」）を書いた帳簿

国税庁のQ&Aでは、インボイス制度の前の「区分記載請求書等保存方式」でも、会社が作った仕入明細書等による控除が認められていたと説明されています。免税のドライバーの支払明細を、経過措置の書類として使える形にすることも考えられます。書く事項や確認の取り方は、税理士と決めてください。

登録済みのドライバーと同じ書式のまま、登録番号の欄だけ空けて出すのは避けましょう。表題や消費税の欄の書き方を、登録の有無で分けておくと、ドライバーにも経理にも分かりやすくなります。

免税のドライバーに消費税の分を払うかどうかは、取引条件の話です。この記事は、報酬を下げることをすすめるものではありません。負担の計算は[控除70%の記事](/articles/invoice-70-percent-driver)、締め日が月の途中の会社は[80%と70%がまざる締めの記事](/articles/shimebi-80-70)をご覧ください。

## 差し引く費用があるとき

軽貨物の支払明細には、管理費やロイヤリティ、車両のリース代などを差し引くものがよくあります。高速代や駐車場代の精算をのせることもあります。

差し引く費用が、会社からドライバーへの売上にあたる場合、その部分は仕入明細書ではなく、会社が出すインボイス（適格請求書）の話になります。どの項目が会社の売上で、どれが立替金の精算かなどで扱いが変わります。1枚の明細にまとめてよいかも含めて、税理士に確かめてください。

まずは、差し引く前の委託料と、差し引く項目を分けて書いておきましょう。そのうえで、項目ごとの扱いを税理士と決めておくと、明細の形が決めやすくなります。

## 保存のしかた

会社は、仕入明細書を原則7年間保存します。期間は、その課税期間の末日の翌日から2か月たった日から数えます。

ドライバーからの確認の連絡や、誤りの連絡があった記録も、明細と一緒に残しておきましょう。明細をメールやアプリで送る場合は、電子帳簿保存法のルールもかかわります。保存の仕方は税理士に確かめてください。

## 月末に見直すチェックリスト

- 表題を、登録済みと免税のドライバーで分けているか
- 作成者（会社名）が書いてあるか
- ドライバーの名前と登録番号が、台帳・公表サイトと合っているか
- 対象期間と、仕事の内容が書いてあるか
- 10%対象の合計額、税率、消費税額が書いてあるか
- 消費税の端数を、明細1枚につき税率ごとに1回で処理しているか
- 確認の文言（例：7日以内に連絡がなければ確認したものとする）が入っているか
- 差し引く費用を、委託料と分けて書いているか

## しめ日ラボでできること

しめ日ラボでは、ドライバーの台帳（登録番号と、公表サイトで確かめた日）から支払明細を作る仕組みを、御社のアカウントに作ります。登録済みのドライバーには「支払明細書（仕入明細書）」として、作成者・登録番号・対象期間・税率ごとの金額と消費税額・確認の文言をのせ、免税のドライバーとは書式を分けます。明細の文言や書式は、御社の顧問税理士に確かめてもらったうえで決めます。どんな明細になるかは[デモ](/demo)でさわれます。免税ドライバーの負担は[計算ツール](/tools/invoice-cost)で、取引条件の明示は[ひな形ツール](/tools/torihiki-joken)で確かめられます。ご相談は[お問い合わせ](/contact)からどうぞ。
