> **この記事のまとめ**
>
> - 業務委託のドライバーに仕事を頼んだら、すぐに取引条件を紙かLINE・メールなどで示します（フリーランス法第3条）。書く事項は決まっていて、口頭だけでは足りません。
> - 単価は「1個150円 × 配達を完了した個数」のような計算のしかたで書けます。何を1個と数えるか、報酬から何をいくら差し引くかまで書いておくと、あとでもめません。
> - LINEやメールで送ってかまいません。送ったメッセージは消さずに控えを残し、ドライバーから紙で求められたら、すぐに渡します。

この記事は、2026年9月時点の公正取引委員会・中小企業庁の資料にもとづいています。ひな形と金額は、すべて書き方の例です。自社の契約に合っているかの最終的な判断は、弁護士・社労士に確かめてください。

## 取引条件明示書（3条通知）とは

フリーランス法（正式には「特定受託事業者に係る取引の適正化等に関する法律」。2024年11月1日施行）の第3条は、フリーランスに仕事を頼んだら、**直ちに**取引の条件を示すことを求めています。これをよく「3条通知」と呼びます。

| 項目 | 内容 |
| --- | --- |
| 示す相手 | 従業員を使わずに1人で走っている個人のドライバー。社長のほかに役員も従業員もいない法人も含みます |
| 示す方法 | 紙か、メール・LINEなどの電磁的方法。どちらにするかは会社が選べます。口頭だけは認められません |
| 示す時期 | 仕事を頼んだとき。新しいドライバーなら走り始める前、スポット便・応援便なら頼んだときです |

法律で決まった書式はありません。業務委託契約書や発注書に書く事項がすべて入っていれば、それで示すこともできます。大事なのは、書く事項がそろっていることです。この記事では「取引条件明示書」と呼びます。

2026年9月2日には、公正取引委員会が日本郵便に対して、取引条件を示していなかったことと、支払の遅れを理由に勧告しています。いきさつは[日本郵便への勧告から学ぶ](/articles/freelance-law-japanpost)にまとめました。

## 書く9つの事項

書く事項は、法律と公正取引委員会の規則で決まっています。軽貨物での書き方の例は次のとおりです。

| 書く事項 | 軽貨物での書き方の例 |
| --- | --- |
| 1. 会社とドライバーの名前 | 会社名と、ドライバーの氏名か屋号。ドライバー番号などの記号でも可 |
| 2. 業務委託をした日 | 仕事を頼むことを話し合って決めた日 |
| 3. 業務の内容 | 宅配便の配達、企業配（ルート配送）、スポット便 など |
| 4. 業務を行う日・期間 | 2026年10月1日〜2027年3月31日 など |
| 5. 業務を行う場所 | 〇〇営業所と、〇〇市の担当エリア など |
| 6. 検査を終える日 | 検査をしないなら不要 |
| 7. 報酬の額 | 「1個150円 × 配達を完了した個数」のような計算のしかたでも可 |
| 8. 支払期日 | 「毎月末日締め、翌月末日払い」のような具体的な日 |
| 9. 現金以外で払う場合の事項 | 銀行振込なら不要 |

### まだ決まっていない事項があるとき

決まっていない事項は、**決まらない理由**と**決める予定の日**を書いておき、決まったら、すぐに示します。ただし、これが認められるのは、仕事の性質上、頼んだ時点ではどうしても決められない事項に限られます。単にまだ決めていないだけ、という事項は、頼むときに決めて書きます。

### 毎回同じ条件は、先にまとめて示せる

同じ仕事を続けて頼む場合は、単価や支払期日など、一定の期間に共通する条件を先にまとめて示しておき、その後の個々の依頼では、どの共通の条件によるものかが分かるように示す方法も認められています。スポット便を何度も頼む会社は、この形にすると手間が減ります。

## ひな形（記入例）

個建ての宅配を頼む場合の記入例です。会社名・単価・金額は、すべて例です。

**取引条件明示書**

株式会社〇〇（以下「当社」）は、〇〇 〇〇 様（ドライバー番号 D-012）に業務を委託するにあたり、取引の条件を次のとおり明示します。

| 項目 | 記入例 |
| --- | --- |
| 業務委託をした日 | 2026年9月25日 |
| 業務の内容 | 宅配便の配達（〇〇営業所の午前便・午後便）。積込み・配達・持ち戻った荷物の返却まで |
| 業務を行う期間 | 2026年10月1日〜2027年3月31日。稼働する日は、前の週の金曜日までにシフト表で決めます |
| 業務を行う場所 | 〇〇営業所と、〇〇市〇〇町・△△町の担当エリア |
| 検査 | 行いません |
| 報酬の額 | 1個150円（税抜）× 配達を完了した個数。不在で持ち戻った荷物は数えず、再配達で完了したときに1個と数えます |
| 報酬から差し引くもの | 管理費 月1万円（税抜）、車両リース代 稼働1日につき1,500円（税抜）。これ以外に差し引くものはありません |
| 支払期日 | 毎月末日締め、翌月末日払い。休業日にあたるときは前の営業日に払います |
| 支払方法 | ドライバーが指定する口座への振込。振込手数料は当社が負担します |
| 費用の負担 | 燃料代はドライバーが負担。高速代・駐車場代は、当社が前もって認めた分を実費で払います |

最後に、日付と会社名を入れます。持ち戻りの扱いや差し引くものは、この例のとおりにする必要はありません。ドライバーと話し合って決めた内容を書いてください。

## 単価（報酬の額）の書き方

具体的な金額を先に示すことが難しい事情があるときは、計算のしかた（算定方法）で示すことが認められています。数量が決まれば、金額がひとつに決まる書き方にします。軽貨物でよく使う単価ごとに、書いておきたい点をまとめます。

### 個建て（1個・1件いくら）

- 何を1個と数えるか。配達を完了した個数か、持ち出した個数か
- 不在で持ち戻った荷物、再配達、集荷の扱い
- 大きな荷物や、1か所に何個も届けるときの数え方
- 個数を何で確かめるか。元請のシステムの実績か、ドライバーの日報か

### 日当（1日いくら）

- 1日の範囲。何時から何時までか、何コースか
- 半日だけ走った日や、途中で終わった日の扱い
- 決めた時間を超えたときに追加で払うか。払うなら、いくらか

### 時間単価（1時間いくら）

- 何分単位で数えるか
- 休憩や、荷物を待つ時間（荷待ち）を含むか
- 始まりと終わりの時刻を何で記録するか

### 月額・距離・便

月額なら、月の途中から始めた月を日割りにするか。距離なら、どこからどこまでを何で測るか。便なら、1便の範囲を書きます。

### 税込か税抜か、費用の扱い

単価が税込か税抜かは、はっきり書いておきます。燃料代・高速代・駐車場代をどちらが負担するかも、書いておくと食い違いません。

インボイスに登録していない（免税の）ドライバーへの支払は、2026年10月1日から、会社が控除できる消費税が80%から70%に下がります。これを理由に、話し合いをせずに一方的に単価を下げたり、差し引きを増やしたりすると、法律の問題になるおそれがあります。会社の負担がいくら増えるかは、[控除70%の計算例の記事](/articles/invoice-70-percent-driver)で確かめられます。

## 報酬から差し引くもの（管理費・ロイヤリティ・リース）

差し引くものは、先に話し合って決め、**名前と金額（または割合）**を明示書に書きます。最後に「ここに書いたもののほかに、差し引くものはありません」と書いておくと、ドライバーも安心できます。

| 差し引くもの | 書き方の例 |
| --- | --- |
| 管理費 | 月1万円（税抜）。月の途中から始めた月は日割り |
| ロイヤリティ | 報酬（税抜）の合計の5% |
| 車両リース代 | 稼働1日につき1,500円（税抜） |
| 任意保険料 | 月〇円。会社の団体保険に入る場合だけ |
| 駐車場代・端末代 | 月〇円 |

割合で差し引くものは、何に対する割合か（税込か税抜か、どの報酬の合計か）まで書きます。

### 気をつけること

- **あとから増やさない**：従業員がいる会社などが1か月以上続く仕事を頼む場合、ドライバーに責任がないのに、決めた報酬を後から減らすことは禁止されています（第5条）。話し合わずに差し引くものを足したり、金額を上げたりすると、これにあたるおそれがあります。
- **無理に使わせない**：正当な理由がないのに、会社が指定する車のリースや保険などを使うよう強いることも、同じく禁止されています。
- **振込手数料は差し引かない**：振込手数料は、会社（支払う側）の負担にしておくのが安全です。取適法（旧下請法）の運用では、合意があっても代金から差し引くと「減額」とされえます。フリーランス法でも、公正取引委員会は、2026年1月1日以後に発注する取引から考え方が変わり、合意があっても報酬から差し引くと「報酬の減額」などにあたりうると案内しています。
- **罰金や弁償**：誤配や遅れの罰金、事故の弁償などを報酬から差し引く取り決めは、判断が難しいところです。明示書に書く前に、弁護士に確かめてください。

## 支払期日の書き方

- 「毎月末日締め、翌月末日払い」のように、締め日と支払日を具体的な日で書きます。「60日以内」のように日がひとつに決まらない書き方は避けます。
- 従業員がいる会社などは、ドライバーが仕事をした日（役務の提供を受けた日）から60日以内の、できるだけ早い日に決めます（第4条）。月単位で締める場合、60日は「2か月」として扱われ、締め期間の最初の日から2か月以内に払います。月末締め・翌月末払いなら、この範囲に入ります。
- 20日締め・翌月末払いのように、締め期間の最初の日から数えると2か月を超える形は、確かめが必要です。毎日続く配達のような仕事では、締め期間の末日までの分をまとめて払うことを話し合って決め、明示書にはっきり書くなどの条件を満たせば、締め期間の末日から数える扱いも認められています。あてはまるかは、弁護士などに確かめてください。
- 支払日が土日・祝日にあたるときに、前の営業日に払うか、次の営業日に払うかも書きます。次の営業日にするなら、60日を超える月がないかも確かめます。
- 請求書が届くのを待たずに、会社の締めで計算して払う形にすると、期日を守りやすくなります。

元請から受けた仕事をドライバーに頼む場合は、決まった事項を書いておくと、支払期日を元請からの支払期日から30日以内で決められる例外があります。書く事項は[日本郵便への勧告から学ぶ](/articles/freelance-law-japanpost)の記事にまとめています。

## LINE・メールで送るとき

- メール、SMS、LINEなどのSNSのメッセージで示してかまいません。ただし、相手を決めて送るものに限ります。ホームページや掲示板に載せるだけでは足りません。
- メッセージで示したあとでも、ドライバーから紙で求められたら、原則として、すぐに紙で渡します。
- 文面が長いときは、A4の明示書をPDFにして送り、メッセージには要点を書くと読みやすくなります。
- 送ったら「確認しました」と返信してもらうと、読んだかどうかが分かります。
- 送ったメッセージは消さずに残します。アカウントの削除や機種変更で見られなくなることがあるので、スクリーンショットやPDFで、ドライバーごとに控えを保存しておきましょう。
- 担当者の個人のLINEで送ると、担当者が辞めたときに記録が残らないことがあります。できれば会社のアカウントから送ります。
- 単価や差し引くものを変えたときも、話し合って決めたら、変えた日と内容を同じように示して残します。

## 契約の期間と、やめるときの予告

明示書に期間を書くときは、更新のしかたと、やめるときの手続も決めておくと安心です。

従業員がいる会社などが、6か月以上続く業務委託を途中で解除したり、更新しなかったりするときは、原則として30日前までに予告する決まりがあります（第16条）。更新して6か月以上続いている場合も含みます。予告のあと、ドライバーから理由を聞かれたら、理由を示す必要があります。災害でやむを得ないとき、ドライバーに責任があるときなど、予告がいらない例外もあります。あてはまるか迷うときは、弁護士・社労士に確かめてください。

## 渡す前のチェックリスト

- 9つの事項がそろっている（検査・現金以外で払う場合の事項は、あてはまらなければ不要）
- 単価は、数量が決まれば金額がひとつに決まる書き方になっている
- 何を1個・1日・1時間と数えるかが書いてある
- 税込か税抜かが書いてある
- 差し引くものは、名前と金額（割合）がすべて書いてあり、振込手数料は入っていない
- 支払日は具体的な日で、60日（2か月）の範囲に入っている
- 送った控えが、ドライバーごとに残っている

## しめ日ラボでできること

[取引条件明示書をつくる無料ツール](/tools/torihiki-joken)では、この記事の項目を埋めるだけで、A4の明示書と、LINE・メールで送る文面ができます。単価は個建て・日当・時間などから選べて、差し引くものも書けます。支払日が60日以内かも、12か月分まとめて確かめます（入れた内容は送信しません）。しめ日ラボでは、ドライバーごとの明示書と、毎月の支払明細・振込データを同じ台帳から作る仕組みを、御社のアカウントに作ります。どんな画面になるかは[デモ](/demo)でさわれます。ご相談は[お問い合わせ](/contact)からどうぞ。
