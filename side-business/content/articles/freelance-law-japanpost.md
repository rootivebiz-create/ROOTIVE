> **この記事のまとめ**
>
> - 2026年9月2日、公正取引委員会は日本郵便にフリーランス法にもとづく勧告をしました。配達などを頼んだ167人に取引条件をすぐに示していなかったこと、140人に支払期日を決めず期日までに払っていなかったことが理由です。
> - 報道によると、先に契約書を作らず、請求書が届いてから払う「請求書払い」の運用が原因とされています。支払期日を決めていないと、法律上は「仕事を受けた日」が支払期日になります。
> - 業務委託ドライバーに仕事を頼む会社は、①条件を先に示す、②60日以内の具体的な支払日を決める、③示した記録と払った記録を残す、の3つを確かめましょう。

この記事は、2026年9月時点の公正取引委員会・中小企業庁の公表資料と報道にもとづいています。自社のやり方が法律に合っているかの最終的な判断は、弁護士・社労士に確かめてください。

## 何があったのか（2026年9月2日の勧告）

2026年9月2日、公正取引委員会は日本郵便株式会社に対して、フリーランス法（正式には「特定受託事業者に係る取引の適正化等に関する法律」）にもとづく勧告をしました。公表と報道で分かっていることは、次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 対象の期間 | 2024年11月1日〜2025年6月30日 |
| 頼んでいた仕事 | 荷物の配達、郵便局の敷地内の除草など |
| 条件を示していなかった | 167人。取引条件の全部か一部を、すぐに書面やメールなどで示していなかった（第3条第1項） |
| 期日までに払っていなかった | 140人。支払期日を決めておらず、仕事を受けた日までに払っていなかった（第4条第5項） |
| 原因とされる運用 | 委託費が一定額以下の仕事は「請求書払い」。先に契約書を作らず、請求書が届いてから払っていた（報道） |

公正取引委員会は、本社・支社や郵便局の一部を抜き出して調べました。報道によると、認定した人数よりも「相当数いた可能性がある」として、会社全体で違反がないかを調べることなどを求めています。

### 勧告の後ろに、多くの指導がある

公正取引委員会の発表では、2025年度（令和7年度）のフリーランス法の勧告は10件、指導は1,542件でした。勧告は、会社名とあわせて公正取引委員会のホームページで公表されています。件数で見ると、措置のほとんどは指導です。

大きな会社だけの話ではありません。フリーランス法のルールは、会社の大きさではなく「誰に、どんな形で仕事を頼むか」で決まります。

## フリーランス法のおさらい

### 守られるのは、1人で働くドライバー

フリーランス法で守られる「フリーランス」（特定受託事業者）は、次のどちらかです。

- 個人で、従業員を使っていない人
- 法人でも、代表者1人のほかに役員がおらず、従業員を使っていない会社

ここでいう「従業員を使う」とは、週20時間以上、かつ31日以上続けて雇う見込みの人を雇うことです。1人で走っている個人の業務委託ドライバーは、ふつうこれにあたります。

### 会社が守ること

| 守ること | 守る会社 |
| --- | --- |
| 取引条件をすぐに示す（第3条） | フリーランスに仕事を頼むすべての事業者 |
| 60日以内の支払期日を決めて払う（第4条） | 従業員がいる、または役員が2人以上いる会社など |
| 減額・買いたたきなどをしない（第5条） | 上と同じ会社で、1か月以上続く仕事を頼む場合 |

従業員を雇ってドライバーに仕事を頼んでいる軽貨物の会社なら、3つとも関係すると考えておきましょう。

### 違反するとどうなるか

違反のおそれがあると、公正取引委員会などの調査を受けます。そのうえで、指導・助言、勧告と進みます。勧告に従わないと、命令や会社名の公表があり、命令に違反したり検査を拒んだりすると、50万円以下の罰金があります。

## なぜ「請求書払い」が危ないのか

請求書を受け取ること自体が問題なのではありません。問題は、条件を先に示さず、支払日も決めずに、請求書まかせにしてしまうことです。

### 1. 条件を「先に」示していない

フリーランス法では、仕事を頼んだら**直ちに**、取引条件を紙かメール・LINEなどで示す必要があります。口頭で伝えるだけでは足りません。

ドライバーが仕事のあとに出す請求書は、会社が頼んだときに示す条件とは別のものです。「単価はいつもどおり」「前と同じで」と口で伝えただけでは、示したことになりません。

### 2. 支払期日を決めていないと「仕事を受けた日」が期日になる

従業員がいる会社などが支払期日を決めていないと、法律上は、**仕事を受けた日そのものが支払期日**になります。60日を超える日を決めた場合は、仕事を受けた日から数えて60日目が支払期日になります。

つまり「請求書が届いたら払う」やり方では、払ったときには、もう期日を過ぎていることがあります。日本郵便の140人のケースは、この形です。

また、「翌月10日まで」「納品後60日以内」のような書き方は、具体的な日が決まらないので、支払期日を決めたことにはならないとされています。

### 3. 軽貨物で同じ形になりやすい頼み方（例）

次のような頼み方が、必ず違反になるわけではありません。ただ、「条件を先に示す」「支払日を決める」がぬけやすい形です。自社に近いものがないか見てください。

- スポット便・応援便を電話で頼み、単価は「いつもので」と済ませている
- 新しいドライバーに「来週から来て」とだけ伝え、単価や管理費は初めての支払のときに説明している
- 単価や、報酬から差し引く管理費・リース代を変えたのに、紙やメッセージで残していない
- ドライバーの請求書が届いた日によって、支払う月がずれる

## 今日から直す3つのこと

### ① 取引条件を示す（明示）

ドライバーに仕事を頼んだら、すぐに次の事項を示します。

| 示す事項 | 軽貨物での書き方の例 |
| --- | --- |
| 会社とドライバーの名前 | 会社名と、ドライバーの氏名か屋号（番号や記号でも可） |
| 仕事を頼んだ日 | 仕事を頼むことを決めた日 |
| 仕事の内容 | 宅配便の配達、企業配（ルート配送）など |
| 仕事をする日・期間 | 2026年10月1日から2027年9月30日まで など |
| 仕事をする場所 | 〇〇営業所と、〇〇市の担当エリア など |
| 検査を終える日 | 検査をしないなら不要 |
| 報酬の額 | 「1個150円 × 個数」のような決め方でも可 |
| 支払期日 | 毎月末日締め、翌月末日払い のような具体的な日 |
| 現金以外で払う場合の事項 | 銀行振込なら不要 |

- LINE・メール・SMSなど、相手を決めて送るメッセージで示してもかまいません。
- メッセージで示したあとでも、ドライバーから紙で求められたら、すぐに渡します。
- まだ決まっていない事項があれば、決まらない理由と、決める予定の日を書きます。決まったら、すぐに示します。
- 管理費・ロイヤリティ・車のリース代などを報酬から差し引くなら、先に話し合って決め、示す内容に入れておきます。従業員がいる会社などが1か月以上続く仕事を頼む場合、ドライバーに責任がないのに、決めた報酬を後から減らすことは禁止されています。

### ② 支払期日を決める（60日ルール）

支払期日は、仕事を受けた日から数えて**60日以内の、できるだけ早い日**に決めます。月ごとに締める会社の場合、公正取引委員会などの資料では、月末締めなら翌月末日までに払う必要があるとされています。

よくある支払のルールを、[取引条件明示書をつくるツール](/tools/torihiki-joken)の60日チェックで確かめると、次のようになります（2026年10月から12か月分で判定。土日などは前の営業日に払う前提）。

| 支払のルール | 60日チェック |
| --- | --- |
| 月末締め・翌月末払い | OK |
| 20日締め・翌月20日払い | OK |
| 20日締め・翌月末払い | 要注意 |
| 月末締め・翌々月10日払い | 要注意 |
| 月末締め・翌々月末払い | 60日を超えます |

「要注意」は、締め期間の最初の日から数えると2か月を超えるものです。締め日から数えてよい条件にあてはまるかを、確かめる必要があります。条件はツールのページにまとめています。

元請から受けた仕事をドライバーに頼む場合は、例外があります。示す内容に、①元請から受けた仕事の再委託であること、②元請の名前（元請だと分かる記号などでも可）、③元請から代金を受け取る支払期日、を書いておけば、ドライバーへの支払期日を、元請からの支払期日から30日以内で決められます。書いていなければ、原則の60日で考えることになります。

### ③ 記録を残す

後から「示した」「期日どおりに払った」と説明できるようにしておきます。

- 示した内容の控えを残す。紙なら写し、LINEやメールなら送ったメッセージを消さずに残し、スクリーンショットも取っておく。
- 単価や差し引くものを変えたときも、変えた日と内容を同じように示して残す。
- 日ごとの稼働（日付・件数）、支払明細、振込の記録を、ドライバーごとにひもづけて残す。

請求書を待たずに、会社の締めで支払額を計算して支払明細を渡す形にすると、期日どおりに払いやすくなります。

## 確かめるためのチェックリスト

- 新しいドライバーには、走り始める前に条件を紙かメッセージで示している
- スポット便・応援便も、頼んだときに単価と支払日を示している
- 支払日は「毎月〇日」のように、具体的な日で決めている
- 支払日は、60日（2か月）を超えていない
- 請求書が遅れても、支払日はずれない
- 示した条件と、支払明細・振込の記録が、ドライバーごとに残っている

あてはまらないものがあれば、この機会に直しておきましょう。自社の頼み方が法律に合っているか迷うときは、弁護士・社労士に相談してください。公正取引委員会や厚生労働省にも、フリーランス法の窓口があります。

## しめ日ラボでできること

まずは[取引条件明示書をつくる無料ツール](/tools/torihiki-joken)を使ってみてください。単価・差し引くもの・締め日と支払日を入れると、A4の明示書と、LINE・メールで送る文面ができます。支払日が60日以内かも、12か月分まとめて確かめられます（入れた内容は送信しません）。しめ日ラボでは、ドライバーごとの明示書と、毎月の支払明細・振込データを、同じ台帳から作る仕組みを御社のアカウントに作ります。どんな画面になるかは[デモ](/demo)でさわれます。ご相談は[お問い合わせ](/contact)からどうぞ。
