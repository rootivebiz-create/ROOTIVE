# 07 30分の商談の台本とヒアリングシート

商談は **30 分・オンラインか電話**。売り込みではなく、相手の今の締め方を聞く場にします。
準備とあとの書類は AI が作ります（→ 03 の 3-3・3-4）。

> 料金は site.config.ts の PLANS が正です。この資料の金額は 2026年9月23日時点の写しです。

---

## 1. 商談の前（AI が 1 枚にまとめる）

- [ ] 相手の会社の要約（公開されている情報だけ）
- [ ] **除外リストに入っていないか**（会社の元請・荷主・お客様・協力会社なら、商談の前に丁寧にお断りする）
- [ ] 予約フォームに書かれたこと（ドライバー数・困りごと）
- [ ] 今回とくに聞く質問 5 つ
- [ ] 見せるデモの場面 2 つ（`/demo` の「稼働」「支払明細」「利益」「振込データ」から選ぶ）
- [ ] 画面共有するタブを開いておく：デモ、提案書（`/kit/proposal?company=【会社名】`）、計算ツール

## 2. 30分の台本

### 0:00〜2:00　あいさつと目的

```text
本日はお時間をいただき、ありがとうございます。【屋号】の【氏名】です。
今日は売り込みではなく、今の月末の締め方をうかがう30分にさせてください。
【会社が認めた場合だけ言う：私も軽貨物の会社をやっていて、毎月の締めで同じようなことをしています。】
最後に、合いそうなら次の一歩を1つだけご提案します。合わなければ、そうお伝えします。
時間は【◯時◯分】までで大丈夫ですか？
```

### 2:00〜17:00　聞く（15 分）

下の「ヒアリングシート」の順に聞きます。全部聞かなくてよいです。**★の付いた質問は必ず聞きます。**
相手が話しているときは口をはさまず、数字はそのまま書き取ります。

最初の一言：

```text
まず、月末にドライバーさんへの支払を決めるまでの流れを、ざっくり教えていただけますか？
稼働の数字が集まるところから、振込が終わるところまでです。
```

### 17:00〜24:00　見せる（7 分）

- 聞いた困りごとに近い場面だけを見せる（全部は見せない）
  - 「控除が複雑」→ `/demo` の「支払明細」
  - 「どの案件で儲かっているか分からない」→「利益」
  - 「振込の入力が大変」→「振込データ」
  - 「免税のドライバーが多い」→ 計算ツール `/tools/invoice-cost`
  - 「明示書を出していない」→ 明示書のツール `/tools/torihiki-joken`
- 言うこと：

```text
これは見本のデータです。実際には、御社の今のExcelのルールで作ります。
仕組みとデータは御社のアカウントに置くので、もし私が保守をやめても、御社の手元に残ります。
最初の1か月は今のExcelと両方で締めて、差がないかを確かめます。
```

### 24:00〜28:00　次の一歩（1 つだけ提案）

下の「5. 次の一歩」から、相手に合うものを **1 つだけ** 提案します（お試し・見積もり・無料診断。まずお試し）。その場で決めてもらおうとしません。
どの商談でも、御社専用の見本と見積を無料で作ってお送りする、という約束はしません。

### 28:00〜30:00　まとめ

```text
今日うかがったことをまとめて、今日中にメールでお送りします。
【お試しの場合：先月分のExcelの送り方もそのメールに書いておきます。】
【見積の場合：3営業日以内に、御社用の提案書と見積をお送りします。】
ほかにご質問はありますか？ 本日はありがとうございました。
```

## 3. ヒアリングシート

商談のあと、AI がこの形に埋めます（→ 03 の 3-4）。

```text
ヒアリングシート　【会社名】　【日付】　話した人：【名前・役職】
何を見て連絡をくださったか：【FAX（見出し：70%／フリーランス法／安全管理者）／メール／紹介（誰から）／検索／その他】

A. 会社
　・事業：【軽貨物／一般貨物／両方】　営業所の数：【】
　・★ 仕組みを入れるかを決めるのは：【社長／ほかの人（誰）】

B. ドライバー
　・★ 人数：業務委託【　】人、社員【　】人（1年前と比べて：増えた／同じ／減った）
　・車両：【ドライバーの自前／会社のリース／両方】

C. 案件と元請
　・★ 元請の数：【】　案件の数：【】
　・元請ごとの締め日：【】
　・元請からの支払通知の形：【PDF／CSV／紙／Webの画面】
　・支払通知と自社の実績を突き合わせているか：【している（誰が・どれくらい）／していない】

D. 単価の種類（当てはまるものすべて）
　・【1個いくら／1日いくら／1時間いくら／1件いくら／距離／車建て／売上の◯%／その他】
　・同じ案件でも、ドライバーによって単価が違うか：【違う／同じ】
　・単価が変わる頻度：【】

E. 控除と調整（当てはまるものすべて）
　・【管理費（定額／%）／ロイヤリティ／車両リース／保険／燃料・ETC・駐車場／事務手数料／立替・前払い／その他】
　・その月だけの調整（手当・差し引き）があるか：【】
　（メモ：一方的な差し引きの良し悪しは、その場で判断しない）

F. 締めと支払
　・★ ドライバーの締め日：【】　支払日：【翌月◯日／翌々月◯日】
　・振込の件数：月【　】件　振り込む銀行：【】
　・全銀形式のデータを銀行にアップロードしているか：【している／手で入力／分からない】

G. 明細
　・★ 今の作り方：【Excel／会計ソフト／手書き／その他】　作る人：【】
　・かかる時間（本人の感覚でよい）：【】
　・★ その人が休んだら、締められるか：【】
　・ドライバーへの渡し方：【紙／PDF／LINE／メール】

H. インボイスと税
　・★ 会社の消費税の計算：【本則課税／簡易課税／2割特例／分からない（→ 顧問の税理士に確認していただく）】
　・インボイスに登録しているドライバー：【　】人中【　】人
　・支払明細を仕入明細書として使っているか：【いる／いない／分からない】
　・顧問の税理士：【いる／いない】

I. フリーランス法
　・取引条件明示書を出しているか：【書面／メール・LINE／出していない】
　・支払期日は、役務の提供から60日以内に収まっているか：【収まっている／超える月がある／分からない】

J. 困りごと
　・★ いちばん困っていること：【】
　・計算や振込を間違えたことがあるか：【】
　・案件別・元請別・ドライバー別の利益を見ているか：【】

K. 検討の状況
　・ほかに見ているもの：【SaaS／kintone／今のまま／その他】
　・★ いつまでに変えたいか：【】
　・予算の感覚：【】
```

## 4. 見込みの判断（進める・様子見・止める）

**進める**（3 つ以上当てはまる）
- 業務委託ドライバーが 5〜50 人
- 月末の明細を Excel か手作業で作っている
- 社長（決める人）が話に出ている
- ルールを説明できる（今の Excel がある）
- 3 か月以内に始めたい
- お試しの金額（PLANS の「先月分でお試し」）を出せそう

**様子見**（無料診断か、3 か月後の連絡）
- 困っているが、時期が決まっていない
- 決める人が別にいて、まだ話していない

**止める・別の案内をする**

| こういうとき | どうするか |
|---|---|
| 会社の取引先（除外リスト）だった | 丁寧にお断りする。理由は「個人の事業の決まりで」とだけ言う |
| ドライバーが 1〜4 人 | 計算ツールと明示書のツールを案内して終える |
| 市販のサービスで形が合っている | 「それがいちばん安いので、そのままがよいと思います」と正直に言う |
| 税金・法律の判断を求められた | 「判断は顧問の税理士・弁護士にお願いします。計算と書類づくりはお手伝いできます」 |
| 免税のドライバーの報酬を一方的に下げたい | 「一方的に下げると、フリーランス法や独占禁止法に触れるおそれがあります。お手伝いできるのは、負担を正しく計算するところまでです」 |
| 大きな会社で、稟議に何か月もかかる | 今回は見送る |

## 5. 次の一歩（1 つだけ提案：お試し・見積もり・無料診断。まずお試し）

### A. お試し（いちばん勧めたい）

```text
先月分でお試しをしませんか。
先月の稼働・単価・控除のExcelをお預かりして、支払明細を自動で計算し、
実際に払った金額と突き合わせます。合わなかった行と、その理由を1枚にまとめてお渡しします。
期間は約2週間、費用は【5万円（税抜）】です。本契約になったら、この費用は初期費用から全額差し引きます。
ドライバーさんの名前は、番号に置きかえて送ってください。口座や住所は要りません。
```

- 送ってもらうもの：先月の稼働・単価・控除の Excel（名前は番号に）、実際に払った合計、控除のルールのメモ
- **口座番号・住所・免許などは、お試しでは受け取らない**
- 発注のとき、お客様から当方へ取引条件（金額・納期・支払期日）をメールなどで示してもらう（フリーランス法）。ひな形は当方から送る

### B. 見積もり（お試しより先に、金額を知りたいとき）

```text
今日うかがったことをもとに、提案書と見積をお送りします。3営業日以内にお送りします。
御社のルールで動くかどうかは、先月分のお試しで確かめていただけます。
決めていただくのは、それを見てからで大丈夫です。
```

- 3 営業日以内に：提案書（`/kit/proposal?company=【会社名】`）と見積書（→ 03 の 3-5・3-6）
- 御社専用の動く見本は、見積の段階では作らない（作るのはお試しか本契約から）

### C. 無料診断（まだ迷っているとき）

```text
まだ決めにくければ、先月分の支払明細を送っていただくだけの無料の診断もあります。
明細の計算の検算、仕入明細書として足りない記載、支払期日、免税の方の分の負担を1枚にまとめてお返しします。
```

### D. 見送り

```text
今日はありがとうございました。今すぐでなくて大丈夫です。
免税の方の負担の計算と、取引条件明示書のページは無料で使えますので、よろしければお使いください。
3か月ほどしたら、一度ご様子をうかがってもよろしいですか？
```

## 6. よくある反論への答え

| 言われたこと | 答え |
|---|---|
| 高い。月1万円くらいのサービスや協会のアプリで十分では？ | 形が合うなら、それがいちばん安いのでおすすめします。合わないのは、控除が複雑な会社や、元請ごとに締めが違う会社です。当方はドライバーが増えても月額は同じです（例：月1.8万円は、1人月1,000円前後のサービスなら18人分）。まず先月分のお試しで、合うかどうかを確かめてから決めてください |
| Excelで回っているから困っていない | 回っているのは、作った方がいるからです。その方が休んだ月に締められるかが分かれ目です。今のExcelをそのまま取り込み、1か月は両方で締めて差を確かめるので、今のやり方を捨てる必要はありません |
| 個人に頼んで、いなくなったらどうする？ | 仕組みもデータも御社のアカウントに置き、ソースと引き継ぎの資料をお渡しします。当方が保守をやめても、別の会社が引き継げる形にします。契約書でもそうお約束します |
| うちのドライバーは使いこなせない | ドライバーさんは、LINEかスマホで明細を受け取るだけです。最初の設定は当方が御社のデータで行い、小さな変更は月額に入っています |
| 補助金は使える？ | 御社のためにゼロから作るものなので、補助金は使えない前提です。その代わり、初期費用を抑え、お試しの費用は本契約で差し引いています |
| ドライバーの口座や個人情報を渡すのが不安 | データは御社のアカウントにだけ置き、当方は必要な範囲だけで作業します。本番の個人情報をAIに入れることはしません。契約には個人情報の取り扱いの取り決めを付けます。お試しは、名前を番号にしたExcelでできます |
| 同業の運送会社の代表に、うちの単価や元請を知られて大丈夫？ | ご心配はもっともです。まず、ファイルをお預かりする前に秘密保持契約を結べます（09 の E-1）。お預かりした数字はその仕事だけに使い、報告書をお渡ししてから30日以内に消して、消したことをお知らせします。また、私が経営している会社と元請・荷主が重なる会社とは、そもそもお取引しない決まりにしています（除外リスト）。本番のデータは御社のアカウントに置くので、当方の手元には残りません |
| 免税のドライバーは70%のぶん報酬を下げればいいのでは？ | 一方的に下げると、フリーランス法や独占禁止法に触れるおそれがあります。まず負担を正しく計算して、話し合いの材料にしてください。最終的な判断は税理士・弁護士にご確認ください |
| 今は忙しい | 相談は今日の30分だけで、あとは資料と録画でご確認いただけます。取り込みも当方で行います |

競合の名前と値段を断定して比べない。出すなら「1人月1,000円前後のアプリ」「2026年9月時点の公開情報をもとにした目安」と言う。

## 8. 商談で言わないこと

- 補助金が使える
- 導入◯社・多数の実績・お客様の声（まだ無い）
- 測っていない時短の数字（言うなら「例」と断り、測ったものだけ）
- 免税ドライバーの報酬を下げるべき
- 会社がドライバーの点呼を代わりにすれば法令対応は完了
- 法令違反をなくせる・税務や法律の判断をする
- 完全自動・ミスゼロ・必ず 1 円まで合う
- 協会の推薦・公認、No.1
- 会社の名前・お客様の名前
