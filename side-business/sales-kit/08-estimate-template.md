# 08 見積書・請求書のひな形

見積書と請求書のひな形です。**【】のところだけ** 書きかえて使います。
AI が契約の内容と `site.config.ts` の金額から埋めて、PDF にします（→ 03 の 3-6）。社長は読んで「送る／直す」を決めるだけです。

> **金額はこの資料に書きません。** 料金は `site.config.ts` の `PLANS`・`OPTIONS` が正です。
> 【】の中の `PLANS の initialYen` などは「そこから写す」という意味です。

---

## 1. 最初に 1 回だけ決めること

- [ ] 屋号・氏名・住所（バーチャルオフィス可）・電話・メール（→ 01）
- [ ] **登録番号（T＋13 桁）**。見積書にも請求書にも必ず書く
  - 最初の請求書は、**登録の通知が届いてから** 出すのがいちばん確実です。間に合わないときは、どう書くかを税理士に確かめます　［税理士］
- [ ] 振込先：屋号の入った事業用の口座（→ 01）
- [ ] 番号の付け方：見積書は `Q-2026-001`、請求書は `I-2026-001` のように通し番号
- [ ] 消費税の端数：**1 枚の請求書につき、税率ごとに 1 回だけ** 端数を処理する（1 円未満は切り捨て）
- [ ] 範囲外の作業の時間単価：【◯円／1時間（税抜）】（→ 09 の保守契約）
  - 時間単価は `site.config.ts` にまだありません。決めたら AI に `site.config.ts` へ足してもらい、この資料には金額を書きません
- [ ] 控えの保存：送った PDF は **PDF のまま** 保存する（紙に印刷して済ませない）。インボイスの控えは 7 年保存とされています　［税理士］

## 2. 見積書のひな形

```text
　　御社のアカウントで各サービスと契約し、御社から直接お支払いいただきます。
　　目安：【月◯円〜◯円程度】（【2026年◯月】時点の各サービスの公開料金をもとにした目安です。
　　　　　使う量や各社の料金改定で変わります）
　・独自のドメインを使う場合：その費用
　・振込データを銀行に送るサービス（法人向けのネットバンキングなど）：御社と銀行のご契約のとおり

　　どちらも、納品日から数えて60日目の方が早いときは、その日までとします。

　・構築の期間：ご契約と資料のお受け取りから【PLANS の weeks】

　・検収のあと【1か月】、今のExcelと両方で締めて、差がないかを確かめます（並行運用）
　・ご契約は、基本契約書・個別契約書・個人情報の取扱いに関する覚書・保守契約書を、電子契約で交わします

6. 前提

　・作るものの範囲は、別紙の仕様のとおりです。範囲の外のものは、別にお見積りします。
　・システムとデータは御社のアカウントに置き、ソースもお渡しします。
　・振込は、御社が金額を確かめて承認してから、御社が行います。当方はお金に触れません。
　・お作りするのは計算と書類づくりの仕組みです。税務・法律の判断はしません。
　　最終的な判断は、税理士・弁護士・社労士にご確認ください。
　・有効期限を過ぎたときは、あらためてお見積りします。

別紙：仕様（見積の範囲）
　・プラン：【支払明細パック】
　・入るもの：【PLANS の includes をそのまま箇条書き】
　・前提の規模：業務委託ドライバー【　】人、元請【　】社、案件【　】件（ドライバーが増えても料金は同じ）
　・単価の種類：【1個・1日・1時間・1件 など、ヒアリングシートの D】
　・差し引くもの：【管理費・ロイヤリティ・リース など、ヒアリングシートの E】
　・今のExcelからの取り込み：【ドライバー・案件・元請の台帳、単価】
　・入らないもの：【例：会計ソフトへの自動の連携、点呼の記録（オプションを付けない場合）】
```

### 見積書を作るときの注意

- 金額は `PLANS` と `OPTIONS` から写す。**プランにない値引き** をするときは、社長が決めて、理由をメモに残す
- お試しをした会社は、お試しの費用を初期費用から全額差し引く（`PLANS` のお試しの `note` のとおり）
- サーバー代は **金額を断定しない**。「目安」「◯年◯月時点」「使う量で変わる」を必ず付ける
- 別紙の仕様は、そのまま 09 の個別契約書の別紙に写す（見積と契約で範囲を食い違わせない）
- 「ミスがなくなる」「◯時間が◯分に」などは書かない

### 支払の日を決めるときの注意（フリーランス法）

- 当方に従業員がいない間は、当方はフリーランス法で守られる側（特定受託事業者）です。
- 御社（発注する側）には、取引の条件を **すぐに書面かメールなどで示す** 義務があります。個別契約書に必要なことを全部書いて、それで示したことにします（→ 09）。
- 御社に従業員がいる（または役員が 2 人以上いる）場合、支払期日は **御社が納品を受けた日から 60 日以内** で、できるだけ短い日にする必要があります。**検収の日から数えるのではありません。**
  - そのため、見積書では残金の期日を「納品日の属する月の翌月末日まで」にしています。月末ごろに納品して検収が翌月にずれても、この日は動かしません。
  - 月の初めに納品すると、翌月末日が納品日から 60 日を少し超えることがあります（例：7月1日に納品 → 8月31日は 62 日目）。そのため「60 日目の方が早いときは、その日まで」と書き添えています。
  - 月額（毎月末締め・翌月末払い）は、月ごとに締める場合の数え方（60 日を「2 か月」として数える扱い）で、無料の道具 `/tools/torihiki-joken` と同じ考え方です。迷ったら弁護士に確かめます　［弁護士］
- 出典：公正取引委員会 フリーランス法の特設サイト https://www.jftc.go.jp/freelancelaw_2025/ ／ 中小企業庁の説明資料 https://www.chusho.meti.go.jp/keiei/torihiki/download/freelance/law_02.pdf

## 3. 請求書のひな形（インボイスの記載事項入り）

月額の保守の例です。初期費用の請求は、下の「内容」の行を差しかえます。

```text
請求書

請求番号：【I-2026-001】
請求日　：【2026年◯月◯日】

【会社名】　御中

【屋号】　【氏名】
〒【郵便番号】【住所】
電話：【050-0000-0000】　メール：【info@ドメイン】
登録番号：【T0000000000000】

下記のとおりご請求申し上げます。

━━━━━━━━━━━━━━━━━━━━
ご請求金額（税込）　【　　　　】円
お支払期日　　　　　【2026年◯月◯日】
━━━━━━━━━━━━━━━━━━━━

取引年月日　　　　　　　　内容　　　　　　　　　　　　　　数量　　単価（税抜）　金額（税抜）　税率
【2026年11月1日〜30日】　保守（【支払明細パック】）11月分　1か月　【　　　】円　【　　　】円　10%
【2026年11月1日〜30日】　保守（【運行記録オプション】）11月分　1か月　【　　　】円　【　　　】円　10%　←付けるときだけ
【2026年11月◯日】　　　　範囲外の変更（【内容】）　　　　 【◯】時間　【　　　】円　【　　　】円　10%　←あるときだけ

─────────────────────────
10%対象　合計（税抜）　【　　　　】円
　　　　　消費税（10%）【　　　　】円
8%対象　 なし
─────────────────────────
合計（税込）　　　　　 【　　　　】円

お振込先：【銀行名】【支店名】【普通】【口座番号】【口座名義（屋号 氏名）】
振込手数料は、御社のご負担でお願いいたします。
```

### 初期費用の請求で差しかえる行

```text
【2026年◯月◯日】　【支払明細パック】の構築（個別契約書【番号】による）残金　1式　【　　　】円　10%
【2026年◯月◯日】　お試しの費用の差し引き　　　　　　　　　　　　　　　　　　　−【　　　】円　10%　←お試しをした会社だけ
```

- 取引年月日は、納品した日（案2 の一括）を書きます。
- **着手金（案1 の着手時 50%）の請求書** は、まだ納品していない時点の請求です。取引年月日の書き方と、消費税をいつの売上にするかを、最初の 1 回だけ税理士に確かめます　［税理士］
  - 迷ったら、案2（検収の翌月末に一括）の方が請求書が 1 枚で済み、扱いが単純です。

### インボイスの記載事項と、ひな形の場所

| 書かなければならないこと | ひな形のどこか |
|---|---|
| 発行する人の氏名または名称と、登録番号 | 【屋号】【氏名】と「登録番号」の行 |
| 取引の年月日 | 「取引年月日」の列（月額は「11月1日〜30日」のように期間でよい） |
| 取引の内容 | 「内容」の列（軽減税率の対象は無いので、「※」の印は要らない） |
| 税率ごとに合計した対価の額と、その税率 | 「10%対象 合計（税抜）」と「税率」の列 |
| 税率ごとの消費税額 | 「消費税（10%）」 |
| 受け取る事業者の氏名または名称 | 「【会社名】御中」 |

- 消費税は、**1 枚の請求書で、税率ごとに 1 回だけ** 端数を処理します（行ごとに消費税を出して足さない）。
- 確かめ先：国税庁「インボイス制度」の特設サイト（記載事項の説明）。最終的な判断は税理士に確認してください。

### 源泉徴収について

- システムの構築・保守の料金は、所得税法204条1項に挙げられた報酬（原稿料・デザイン料など）に当たらず、源泉徴収は要らないとされています（国税庁 タックスアンサー No.2792 https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm ）。そのため、ひな形に源泉徴収の欄は作っていません。最初の請求の前に、1 回だけ税理士に確かめます　［税理士］
- デザイン料などを分けて請求するときは、扱いが変わることがあります。最初の 1 回だけ税理士に確かめます　［税理士］

## 4. お試しの請求書（1 回だけ）

```text
取引年月日　　　　　内容　　　　　　　　　　　　　　　　　　　数量　金額（税抜）　税率
【2026年◯月◯日】　先月分でお試し（【2026年◯月】分の計算と報告書）　1式　【お試しの initialYen】円　10%

備考：本契約（【支払明細パック】以上）になった場合は、この金額を初期費用から全額差し引きます。
```

- 取引年月日は、報告書を渡した日。
- お支払期日は、報告書を渡した日の属する月の翌月末日（渡した日から数えて 60 日目の方が早いときは、その日）。

## 5. AI への頼み方

見積書は 03 の 3-6 をそのまま使います。請求書は次の文です。

```text
【会社名】の【11月分の保守／初期費用の残金／お試し】の請求書を作って。
- sales-kit/08-estimate-template.md の 3 か 4 のひな形で
- 金額は、交わした契約書（個別契約書・保守契約書）の金額から。site.config.ts の PLANS と違ったら、契約書を正にして私に知らせて
- 取引年月日・お支払期日・登録番号・振込先を確かめて
- 消費税は税率ごとに1回だけ端数を処理（1円未満は切り捨て）
- 範囲外の作業があれば、作業の記録（日付・内容・時間）を下に付けて
PDF にできる形で。送る前に私が読みます。
```

## 6. 送る前のチェック

- [ ] 宛名の会社名が正しい（除外リストの会社ではない）
- [ ] 登録番号・屋号・氏名・住所が入っている
- [ ] 金額が `PLANS`・`OPTIONS`（請求書は契約書）と合っている
- [ ] 税抜・消費税・税込が分かれていて、足し算が合っている
- [ ] 支払期日が、納品を受けた日から 60 日を過ぎていない（初期費用）／月末締め翌月末払い（月額）
- [ ] サーバー代を当方の請求に入れていない。金額を断定していない
- [ ] 「ミスゼロ」「必ず合う」「補助金」「導入◯社」などの言葉が入っていない
- [ ] PDF の控えを保存した
