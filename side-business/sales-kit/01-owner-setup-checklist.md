# 01 開業と準備のチェックリスト

上から順にやれば、営業を始められる状態になります。期限は **2026年10月1日に開業する場合** の例です。開業日を変えたら、期限もずらしてください。

- ［税理士］［弁護士］［司法書士］の印は、自分だけで決めずに専門家に一度確かめるものです。
- 「AI」と書いたところは、Claude Code に頼めば下書きや手順を作ります（頼み方は 03）。

---

## A. いちばん最初に（営業を始める前・9月中）

- [ ] **会社の承認と議事録**（→ 02）　期限：最初の営業の前　［司法書士］［弁護士］
  - 小さな運送会社に仕組みの構築と保守を売ること、会社のコード・データ・人・時間を使わないこと、会社の元請やお客様に営業しないこと、週 2 時間までを書く
- [ ] 会社として、次の 2 つを認めるかを決め、議事録に残す（→ 02 の別紙 7）
  - 「現役の軽貨物会社の代表が作っている」と書いてよいか（会社名・画面・データは出さない）
  - 自社の月末の締め作業の時間を、名前を出さない例として使ってよいか
- [ ] **屋号の商標チェック**　期限：サイト公開の前
  - 特許庁の J-PlatPat（https://www.j-platpat.inpit.go.jp/）で「しめ日ラボ」と似た名前を調べる。ソフトウェアやシステム開発の区分（第42類・第9類など）を見る　［弁理士に聞くと確実］
  - 同じ屋号の会社がないか、ネットで検索する（AI が調べる）
  - 会社の名前と明らかに違う名前にする
- [ ] 開業日を決める（例：2026年10月1日）
- [ ] 同業の知り合いの一覧を作る（→ 04）。**会社の取引先は入れない**
- [ ] 除外リストを作る（会社の元請・荷主・お客様・協力会社の会社名だけ）

## B. 開業の手続き（10月1週目）

- [ ] **e-Tax で 3 つをいっしょに出す**（マイナンバーカードでログイン。会計ソフトの無料の開業届サービスからでも出せる）

| 出すもの | 期限（10月1日開業の例） | メモ |
|---|---|---|
| 開業届（個人事業の開業・廃業等届出書） | 2026年10月31日まで（開業から1か月以内） | 屋号を書く |
| 適格請求書発行事業者の登録申請（インボイス） | 10月中に出す | 開業した年のうちに出せば、開業の日から登録したことになる（国税庁 Q&A）。個人の場合の書き方は原文で確かめられていない ［税理士］ |
| 青色申告の承認申請 | 2026年12月1日まで（開業から2か月以内） | 65万円の控除を受けるには、複式簿記と、e-Tax での申告（または優良な電子帳簿）が要る ［税理士］ |

- [ ] 登録の通知が届いたら、登録番号（T＋13桁）を控える
  - 国税庁の公表サイトに **本人の氏名** が出ます。屋号を載せるかは選べる（未確認）
  - サイト（`INVOICE_REG_NO`）、見積書、請求書、FAX の原稿に必ず書く
- [ ] **なぜ登録するのか**（決めたことのメモ）
  - 登録しないと、本則課税のお客様は当方への支払の一部を控除できなくなり、値下げを求められやすい
  - 「インボイスに合った明細を作る」ことを売るのに、売る側が未登録では信用されない
  - 納める消費税の目安（税抜の売上に対して）：2026年分は 2割特例で約2%、2027年分と2028年分は 3割特例（個人だけ）で約3%、2029年分からは簡易課税を選べば約5%　［税理士］
- [ ] **事業用の銀行口座** を屋号で作る（開業届の控えが要ることが多い。e-Tax の受信通知で足りるかは銀行に確認）
  - 会社の口座と絶対に混ぜない。お客様からの入金・経費の支払いはこの口座だけ
- [ ] 会計ソフトを決める（複式簿記・e-Tax に対応したもの）　［税理士］
- [ ] 印紙税と源泉徴収の扱いを税理士に 1 回聞く（電子契約なら印紙が要らないとされる点、紹介のお礼の扱いも）　［税理士］

## C. 連絡の窓口（10月1週目）

会社のメール・電話・LINE・名刺は使いません。

- [ ] **事業用のメール**（独自ドメイン。例：`info@【ドメイン】`）
  - 営業のメールが迷惑メールに入らないよう、SPF・DKIM・DMARC を設定する（AI が手順を作る）
- [ ] **050 の電話番号**（スマホのアプリで受けられるもの）
  - 出られないときは留守番電話にし、折り返す
- [ ] **LINE 公式アカウント**（屋号で作る）
  - 無料のプランから始める（無料で送れる通数の上限は公式ページで確認）
  - 友だち追加の URL を `NEXT_PUBLIC_LINE_URL` に入れる
- [ ] **予約カレンダー**（Google カレンダーの予約スケジュールなど）
  - 1 枠 30 分、週 2 枠まで、前日までの予約にする（社長の時間を守るため）
  - 予約ページの URL を `NEXT_PUBLIC_BOOKING_URL` に入れる
- [ ] **表に出す住所**：バーチャルオフィスでもよい。営業のメールと FAX には住所を必ず書く（→ 05・06）
  - 自宅の住所を出したくないなら、バーチャルオフィスを借りる　［税理士：開業届の納税地との関係］

## D. サイト（10月1週目）

- [ ] **ドメインを取る**（屋号に近いもの）
- [ ] **サイトのソースを個人の GitHub アカウントで管理する**（会社のリポジトリ・会社のアカウントに置かない）
  - いまは会社のリポジトリの中（`side-business/` のフォルダ）で作っている。**営業を始める前に、個人のリポジトリへ移す**（AI に「side-business を個人のリポジトリに移す手順を作って」と頼む）
  - 移したあとは、Claude Code もその個人のフォルダで開く（会社のリポジトリの中で開くと、会社の設定も読み込まれるため）
- [ ] **Vercel は個人のアカウント**（会社のアカウント・会社の請求先を使わない）
  - 無料（Hobby）プランは商用で使えない決まりになっている。料金ページと規約を確かめ、必要なら Pro にする
- [ ] 環境変数を入れる（Vercel の Settings → Environment Variables）

| 変数 | 入れるもの |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | 本番の URL（例：`https://【ドメイン】`）。FAX やチラシの QR がここを指す |
| `OWNER_NAME` | 事業者の氏名 |
| `BUSINESS_ADDRESS` | 表に出す住所 |
| `BUSINESS_PHONE` | 050 の番号 |
| `INVOICE_REG_NO` | 登録番号（T＋13桁。通知が来てから） |
| `NEXT_PUBLIC_CONTACT_EMAIL` | 事業用のメール |
| `NEXT_PUBLIC_BOOKING_URL` | 予約ページ |
| `NEXT_PUBLIC_LINE_URL` | LINE 公式アカウントの友だち追加 URL |
| `RESEND_API_KEY` と `CONTACT_TO_EMAIL` | 相談フォームの中身をメールで受け取る（`CONTACT_FROM_EMAIL` は送り主。独自ドメインにするなら Resend 側の設定が要る） |
| `CONTACT_WEBHOOK_URL` | 相談フォームを Slack や Discord でも受け取るとき（任意） |

- [ ] 公開したら、自分で相談フォームを 1 回送って、届くか確かめる。`?utm_source=test` を付けた URL から開いて送り、通知に「流入元：utm_source=test, …」の 1 行が入るかも見る（→ 06・13）
- [ ] Vercel の管理画面で Web Analytics を有効にする（FAX の QR やメールのリンクから来て、問い合わせにならなかった訪問も数える → 06・13）
- [ ] スマホで、トップ・計算ツール・デモ・相談のページを開いて崩れがないか見る
- [ ] デモは **ダミーデータだけ**。会社のデータは 1 行も入れない
- [ ] Google アナリティクスなどのアクセス解析を入れるなら、プライバシーポリシーと合っているか見る（AI が確認）

## E. 保険と契約の準備（最初の商談の前まで）

- [ ] **フリーランス協会** に入る（一般会員 年1万円。賠償責任保険が付く）
  - 仕事のミスで相手にお金の損が出たとき（ケガや物の壊れが無いもの）の補償は 500万円までで薄い
  - 最初の契約が決まったら、IT の仕事向けの賠償保険の見積を取る
- [ ] **契約書のひな形一式（→ 09）を弁護士に一度見てもらう**　［弁護士］
  - 基本契約、構築（請負）、保守（準委任・毎月自動更新）、個人情報の取り扱いの取り決め、秘密保持
  - 「振込は必ずお客様が金額を確認してから行う。当方はお金に触れない」を入れる
- [ ] お客様から当方に出してもらう **発注書（取引条件の明示）** のひな形を用意する
  - お客様は、当方（フリーランス）に仕事を頼むとき、取引条件をすぐに書面かメールなどで示す必要がある（フリーランス法）
  - お客様に従業員がいる（または役員が 2 人以上いる）なら、当方への支払期日は、納品を受けた日から 60 日以内
- [ ] 見積書・請求書のひな形（屋号・氏名・住所・登録番号・税率ごとの金額 → 08）

## F. 営業の準備（10月2週目）

- [ ] **全国軽貨物協会** に、賛助会で何ができるか・個人でも入れるかをメールで聞く（文面は 11）
  - 公開情報の目安：地域 1 つで月3,000円、全国で月10,000円、1年契約・自動更新
  - 入るのは返事を見てから。協会の推薦や公認とは書かない
- [ ] **FAX の業者** 2〜3 社に、軽貨物だけのリストの有無と件数を聞く（→ 06）
- [ ] **Google 広告** のアカウントを作り、キーワードプランナーで検索数と単価を見る（広告はまだ出さない）
- [ ] **営業記録のスプレッドシート** を作る（Google スプレッドシート。Git には入れない）
  - シート：送付記録／停止リスト／除外リスト／反響／商談／紹介／KPI（→ 04・05・06・13）
