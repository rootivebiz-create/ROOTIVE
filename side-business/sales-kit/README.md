# しめ日ラボ 営業キット

社長が **週 1〜2 時間** だけで、しめ日ラボの営業を回すための手順と文面のセットです。

- 文面はコピーしてそのまま使えます。**【】のところだけ** 書きかえてください。
- **{製品のデモの URL}** は、製品のデモの入口です。Vercel の環境変数 `NEXT_PUBLIC_PRODUCT_DEMO_URL` に入れた URL の末尾に `/demo/start` を付けたもの（例 `https://shimebi-demo.vercel.app/demo/start`）。**まだ公開していなければ、その行ごと消して** 送ります（壊れたリンクを送らない）。
- 下書き・調べもの・記録は AI（Claude Code）が作ります。社長は「読む」「OK／やめる」「商談で話す」だけです。
- 料金は `site.config.ts` の `PLANS` が正です。この資料に出てくる金額は 2026年9月23日時点の写しです。料金を変えたら `PLANS` を直し、AI に「営業キットの金額を PLANS に合わせて」と頼みます。

## 売るもの：製品「しめ日ラボ」（お客様に納めるもの）

業務委託ドライバーに支払う会社（5〜50 人ほど）の、**月末の締めをまとめて引き受ける Web アプリ** です。
お客様 1 社ごとに、**お客様名義の Vercel ＋ Postgres** に置きます（データはお客様のもの）。立ち上げはオーナーが行います。
画面と立ち上げの手順は [`../product/README.md`](../product/README.md)、何を・なぜ・言ってはいけないことは [`../product/SPEC.md`](../product/SPEC.md) にあります。

### 話す順番（どの資料・商談でも同じ）

1. **元請の支払通知との突合**：「元請の支払通知と、自社の記録が合っているか。先月分で、差を金額でお見せします（お試し 5 万円）」
   通知を置くと、自社の記録（数量 × 受注単価）と案件ごとに比べ、**少ない可能性がある差** を金額で出す。丁寧な問い合わせ文の下書きまで。送るかどうかはお客様が決める
2. **10 月 1 日からの経過措置**：免税ドライバーへの支払の控除が 80% → 70%。例：税込 11 万円の支払で、会社の負担は 1 人・月 2,000 円 → 3,000 円（原則課税の会社）
3. **Excel をそのまま取り込み**：形を変えずに置くだけ。打ち直し不要。形と名前の表記ゆれを覚える
4. **並行運用**：先月分を今の Excel と 1 人ずつ比べ、差と原因の候補を出す。全員が一致するか、差の理由が分かってから切り替える
5. **ドライバーが納得する明細**：リンクで渡す（アプリもパスワードも不要）。「確認しました」の記録と、行ごとの質問。その記録は、明細を仕入明細書として使うときの相手方の確認の記録として使える形（国税庁 Q&A 問86 の方法に沿う。最終的な判断は税理士と）
6. **締め前の見張り番**：取引条件の明示・合意の無い控除・口座・支払期日・免税の方の分の負担などを、記録から分かる事実と根拠つきで。**判断はしない**
7. **データは御社のもの**：御社名義のサーバーに置く。全データをいつでも書き出せる

### 「今の道具で十分」と言われたら

Excel の取り込みや会計ソフトへの出力がある運送向けのサービスで足りているなら、**それがいちばん安い** と正直に言います。
しめ日ラボが足すのは 4 つだけ：**元請との突合**・**ドライバーの確認の記録**・**締め前の見張り番**・**立ち上げは当方、データは御社**。どれも要らなければ、今のままをすすめます（→ 07 の 6）。
**ほかの製品の名前は出さない。比べて悪く言わない。「ほかには無い」とも言わない**（相手のページを確かめられていないため）。

### 画面（製品の README の表の要約）

| 画面 | 使うところ |
|---|---|

## 守ること（全部の資料に共通）

1. **会社の名前・画面・データ・コード・お客様の名前を、出さない・使わない。**
2. **会社の元請・荷主・お客様には営業しない。** 紹介を頼むのも、メールや FAX を送るのも、しない。除外リストで毎回確かめる。
3. **始める前に、会社の承認と議事録を済ませる**（→ 02）。
4. **言わないこと**（資料・メール・口頭のすべて。製品の `SPEC.md` の §8 と同じ）
   - 「補助金が使えます」
   - 作った実績・お客様の声・導入◯社・削減時間（出してよいのは、お試しで測ったお客様自身の数字を、同意を得て「例」として使うときだけ）
   - 「完全自動」「ミスゼロ」「必ず合う」「1 円まで必ず合う」（言えるのは「合うかを 1 人ずつ確かめてから切り替える」）
   - 「法令に完全対応」「適法です」「違反はありません」「違反です」「これで監査は大丈夫」「勧告を防げます」
   - 「仕入税額控除できます」（言えるのは「仕入明細書の記載事項を載せる形」「国税庁 Q&A 問86 の方法に沿った確認の記録を残す」まで）
   - 「未払いを取り戻せます」「未払いです」（言えるのは「少ない可能性がある差を金額で見つける」「確認のお願いの下書きを作る」まで。取り戻せるかは元請しだい）
   - ドライバーの報酬を下げましょう・免税の方の単価を見直しましょう（どんな形でも言わない）
   - 税務・法律の判断（「最終的な判断は税理士・弁護士・社労士に」で締める）
   - ほかの製品の名前、ほかの製品との比べ、「どこにも無い」「他社にはない」「唯一」「日本初」「No.1」
   - 協会の推薦・公認、国のお墨付きをにおわせること
   - 会計ソフトに「対応」（製品の体験版で取り込めた記録を残すまで。言えるのは「取り込む CSV を出せます。形式は税理士さんと確かめてください」）
5. **言ってよいこと**：製品がすること（画面で見せられること）／最終的な判断は税理士・弁護士に残すこと／お試しは、お客様自身の先月分の本当の数字で測ること。
6. 送る前に社長が OK を出す。**停止の申し出はその日のうちに止める。**
7. ドライバーの名前・口座・免許などの本番の個人情報を AI に入れない。
8. 会社のパソコン・スマホ・メール・LINE・名刺を使わない。
9. 無料診断・お試しで預かったファイルと、お試し用の製品のデータは `side-business/private/` に置く（Git には入らない）。終わったら 30 日以内に消す（→ 03・10）。

## 1 週間の動き（ひと目で）

| いつ | 時間 | やること | 資料 |
|---|---|---|---|
| 月曜の朝 | 10分 | AI の週報を読み、今週送るものに「OK／やめる」を返す | 03 |
| 予約が入った日 | 30分 × 1〜2件 | 商談（5 分の製品のデモつき） | 07 |
| いつでも | 10分 | 同業の知り合い 1〜2 人に、紹介のお願いを送る | 04 |
| いつでも | 10分 | AI が作った見積書・提案書・レポートを読んで、送るか決める | 03・07 |
| **お試しがある週だけ** | **45〜60分** | **お試しの納品物を製品で作る**（手元の製品に先月分を入れ、並行運用レポート・突合レポートを出す） | 03 の 3-8・10 |
| 導入中のお客様がいる週だけ | 30分 | 立ち上げの打ち合わせか検収の立ち会い | 製品の README |
| 月初に 1 回 | 15分 | 先月の数字を見る。FAX の見出しを決める | 06・13 |
| その日のうちに | 1分 | 停止の申し出を止める | 03・05・06 |

合計は **週 60〜120 分**。お試しがある週は、商談を 1 件までにします。2 時間を超えそうなら、新しい商談は翌週へ回します。
AI への頼み方（そのまま貼れる文）は 03 にまとめてあります。

## 記録の置き場所

営業の記録（送った相手・停止・反響・商談）は、**Google スプレッドシート「しめ日ラボ_営業記録」** に置きます。
相手の会社の情報が入るので、**Git には入れません**（このフォルダに記録のファイルを作らない）。
お客様から預かったファイル（Excel・CSV・PDF）と、お試しで製品に入れたデータは `side-business/private/` にだけ置きます（`.gitignore` で外してあるので Git に入りません）。
